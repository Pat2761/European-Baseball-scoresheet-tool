Description de l’outil

Ce chapitre décrit l’environnement dans lequel on peut saisir les matchs de baseball. Cet outil est basé sur l’environnement Eclipse et utilise les possibilités offertes par celui-ci.

Eclipse est un framework qui fournit des ressources permettant de créer des applications contenant des vues et des éditeurs. Il fournit également des mécanismes pour créer des menus et des menus contextuels, ainsi qu’un éditeur de préférences (ou d’options), entre autres fonctionnalités que nous ne détaillerons pas dans ce document.

Cette application fournit donc des vues et deux éditeurs spécialement conçus pour le baseball. Le premier éditeur sert à décrire un club, avec le nom des joueurs et des officiels ; le second permet de décrire les actions et les intervenants d’un match. L’application propose également plusieurs vues : une vue permettant de définir un championnat, de créer les clubs et les matchs qui le composent et de les répertorier ; une vue « Infield », qui affiche la position des joueurs à un instant donné du match ; un tableau de score ; des vues graphiques des feuilles de scorage ; le lineup en cours de match ; ainsi que d’autres vues. L’outil réutilise aussi des vues standard, comme la vue « Problèmes », qui répertorie les erreurs et les avertissements détectés dans votre saisie.
