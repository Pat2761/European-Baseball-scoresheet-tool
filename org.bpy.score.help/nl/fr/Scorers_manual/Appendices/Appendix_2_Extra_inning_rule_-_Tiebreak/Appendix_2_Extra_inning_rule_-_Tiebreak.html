Annexe 2

Règle relative aux manches supplémentaires / Tiebreak

Symbole de notation TIE

Si le match demeure à égalité après l’achèvement de neuf (9) manches, les procédures suivantes seront appliquées durant les manches supplémentaires :

Chaque équipe entamera la 10ieme manche (ainsi que toute manche supplémentaire nécessaire par la suite) avec un joueur en première base et un autre en deuxième base, sans aucun retrait.

Au début de la 10ieme manche, des représentants de chaque équipe se réuniront au marbre et indiqueront (simultanément) à l’arbitre principal à quel point de l’alignement des frappeurs leur équipe souhaite commencer. En d’autres termes, les équipes ont la possibilité de débuter la 10ieme manche à n’importe quel rang de l’alignement des frappeurs tel qu’il était établi à la fin de la 9ieme manche. Il est important de noter qu’il ne s’agit pas d’un nouvel alignement (mais potentiellement d’un ordre différent) ; il peut très bien s’agir du même ordre que celui en vigueur à la fin de la 9ieme manche. L’objectif de cette mesure est de garantir que les deux équipes aient des chances égales de placer leurs meilleurs frappeurs et coureurs selon leur propre évaluation dans une position favorable pour marquer des points durant la 10ieme manche.

Par exemple : si l’équipe décide de faire passer en premier le frappeur occupant le 5ieme rang de l’alignement, alors le frappeur occupant le 3ieme rang sera placé en deuxième base, et celui occupant le 4ieme rang sera placé en première base. Par ailleurs, si l’équipe décide de faire passer en premier le frappeur occupant le 2ieme rang de l’alignement, alors le frappeur occupant le 9ieme rang sera placé en deuxième base, et celui occupant le 1ier rang sera placé en première base.

WBSC Transcription dans l'outil de scorage Outil
/* 10ieme manche */
inning hometeam number 10 {
   /* Retrait du frappeur sur des prises */
   action { batter -> KS }

   /* Retrait du frappeur sur des prises */
   action { batter -> KS }

   /* Le frappeur réussit un simple vers le champ gauche. */
   action { ;batter -> 1B7 }

   /* Retrait du frappeur sur des prises */
   action { batter -> KL }
}

/* 10ieme manche */
inning visitor number 10 {
   /* Tie break */
   specialSituation { tieBreak }
}

Une fois ces joueurs (ou coureurs) déterminés pour la 10e manche, l’ordre de passage pour les manches suivantes dépendra de la manière dont la manche précédente s’est terminée. Ainsi, si la 10ieme manche s’achève alors que le 5ieme frappeur de l’alignement effectue son passage au bâton, la 11ieme manche débutera avec le 6ieme frappeur au bâton, tandis que le 4ieme frappeur sera placé en deuxième base et le 5ieme frappeur en première base.

WBSC Transcription dans l'outil de scorage Outil
/* 9ieme manche */
inning hometeam number 9 {
...
   /* Le frappeur réussit un simple vers le champ gauche. */
   action { batter -> 1B7 }

   /* Retrait du frappeur sur des prises */
   action { batter -> KL }
}

/* 10ieme manche */
inning visitor number 10 {
   /* Tie break */
   specialSituation { tieBreak }

   /* coureur éliminé pour avoir été pris en train de voler une base */
   action { runner2 -> CS25 }

   /* Double jeu sur une balle au sol */
   action { batter -> GDP43 , runner1 -> 54 }

}

Aucune ré entrance d’un joueur n’est autorisé durant les manches supplémentaires.
Le système traditionnel, selon lequel l’équipe visiteuse passe au bâton en début de manche et l’équipe locale en fin de manche (si nécessaire), demeure en vigueur jusqu’à ce qu’un vainqueur soit désigné.
Tout coureur commençant en deuxième base (2B) ou en première base (1B) dans le cadre de la règle du tie break ne se verra créditer ni passage au bâton (PA), ni présence officielle au bâton (AB).
Un point marqué par des joueurs qui, au début de l’action, occupaient les première et deuxième bases, est porté au compte de l’équipe en défense et non à celui du lanceur ; il ne peut donc, par définition, être considéré comme un point mérité. Quant à savoir si un point marqué par tout autre joueur doit être porté au compte du lanceur, cela relève de l’appréciation du scoreur officiel.

WBSC Transcription dans l'outil de scorage Outil
/* 10ieme manche */
inning visitor number 10 {

   /* Tie break */
   specialSituation { tieBreak }

   action { batter -> O1b (3) , runner1 -> + (3)+ , runner2 -> E1T+ }

   action { batter -> 1B9 , runner2 -> + }

   action { runner3 -> WP }

   action { batter -> 2B7 , runner1 -> +++ earned }

   action { batter -> 43 , runner2 -> + }

   action { batter -> SF7 , runner3 -> + }

   action { batter -> KS }

Si une action entreprise par un frappeur suivant par exemple, un choix défensif entraîne le retrait du coureur qui occupait la position la plus avancée, le premier point marqué au cours de cette manche peut être porté au compte de l’équipe. (Exemple : si un coureur atteint la première base en toute sécurité à la suite d’un choix défensif par exemple, lors d’un retrait effectué entre le premier et le troisième but, ce nouveau coureur est tout de même porté au compte de l’équipe.)
Si le coureur qui occupe la deuxième base est retiré sans intervention du frappeur (retiré en tentant de voler un but, pris au piège hors de sa base ou ayant quitté sa base trop tôt), alors aucun point n’est porté au compte de l’équipe.

WBSC Transcription dans l'outil de scorage Outil
/* 10ieme manche */
inning visitor number 10 {

   /* Tie break */
   specialSituation { tieBreak }

   action { batter -> O6 , runner1 -> O6 , runner2 -> 64 }

   action { batter -> HR9 earned , runner1 -> +++ , runner2 -> ++ }

En cas de changement de lanceur au début de la manche supplémentaire, il est très important d'indiquer ce changement au-dessus des deux joueurs placés sur les bases en début de manche. La manche supplémentaire a pour vocation de permettre la réalisation du point de la victoire, ce qui détermine les statistiques à attribuer aux lanceurs. Un point marqué par l'un des joueurs ayant débuté la manche sur les bases doit être porté au débit du lanceur de relève.

WBSC Transcription dans l'outil de scorage Outil
/* 10th inning */
inning visitor number 10 {

   /* Tie break */
   specialSituation { tieBreak }

   /* pitcher replacement */
   substitution hometeam { player 1 replaceBy "WILLIS Bruce" shirtNumber= 32 at 1 }
