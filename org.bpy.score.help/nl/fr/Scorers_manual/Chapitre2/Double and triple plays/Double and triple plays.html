Doubles et triples jeux.

Conformément à la définition des termes de OBR,un double ou un triple jeu est " une action de la défense au cours de laquelle deux ou trois joueurs offensifs sont éliminés à la suite d'une action continue, à condition qu'il n'y ait pas d'erreur entre les éliminations."

Le scoreur officiel doit créditer la participation à un double jeu ou à un triple jeu à chaque joueur de la défense qui effectue un retrait ou une assistance lorsque deux ou trois joueurs sont retirés entre le moment où un lancer est effectué et le moment où la balle devient morte ou est de nouveau en possession du lanceur en position de lancer, à moins qu'une erreur ou une faute de jeu n'intervienne entre les retraits. [OBR 9.11].

Par conséquent, sur la feuille de pointage (colonne du côté de la défense), la participation à un double jeu ou à un triple jeu doit être créditée à chaque joueur de champ qui a participé à l'action.

IMPORTANT: Il convient également de rappeler qu'une erreur ou une mauvaise action (même si elle n'est pas enregistrée comme telle) interrompt le double ou le triple jeu.

Le symbole utilisé est un cercle unique autour des retraits et une ligne reliant les deux ou trois cercles.

Le scoreur officiel doit également créditer un double jeu ou un triple jeu si une action d'appel après que la balle soit en possession du lanceur entraîne un retrait supplémentaire. [OBR 9.11, Comment].

Le nombre total de doubles et/ou triples jeux Les nombre de double ou triple jeux eccectués chaque équipe doivent être inscrits dans le carré situé au-dessus des statistiques défensives des lanceurs, à droite de la mention « DOUBLE JEUX ». La ligne des totaux sous la colonne « DP » doit indiquer le nombre total de fois où chaque joueur de champ a participé à un double ou un triple jeu.

  1. Double jeu inversée [OBR Definition of Terms]. " Il s'agit d'une situation où le premier retrait est un jeu forcé et le second un retrait sur un coureur dont le jeu forcé est annulé par le premier retrait. Exemple de jeu forcé inversé : coureur en première base, un retrait ; le frappeur frappe un roulant vers la première base, qui touche la première base (un retrait) et relance vers le défenseur de la deuxème base ou à l'arrêt-court pour le second retrait (un jeu de tag). Lorsque le dernier coureur est éliminé, le ou les coureurs de tête ne sont plus obligés d'avancer et doivent être éliminés à leur tour.

    Les mêmes symboles sont utilisés pour indiquer ce type de double ou triple jeu que pour les autres.

  2. Balle roulante dans un double jeu - Cette faute est reprochée au frappeur lorsque la situation sur le terrain répond aux critères suivants :
    1. Moins de deux retraits.
    2. Un ou plusieurs coureurs contraints d'avancer (ou de reculer).
    3. Une balle au sol vers l'intérieur du terrain qui aurait permis deux ou trois retraits, ou qui aurait permis d'en obtenir deux ou trois sans des erreurs décisives.

Si le double ou le triple jeu résulte d’une « interférence d’un coureur précédent », le scoreur officiel n’imputera pas un double jeu au frappeur sur un roulant. [OBR 9.02 (a) (17) Comment]

Le symbole d'un double jeu est « GDP », inscrit dans le cercle indiquant l'élimination du frappeur concerné, ou, s'il a atteint la première base, dans la case de la ppremière base. Chaque fois que les initiales « GDP » apparaissent sur la feuille de match, un double jeu doit être comptabilisé contre le frappeur en question dans la colonne appropriée de la feuille de match de l'équipe offensive.

Example 1: Avec la première base occupée, le batteur frappe une ‘Line drive’ qui est rattrapéé par le défenseur de la deuxième base.
Le coureur qui avait quitté la première base, tente de la rejoindre, mais il est touché par le joueur de la première base assisté par le joueur de la deuxième base qui lui a relayé la balle.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier batteur avance sur un BB */
action { batter -> bb }

/* Deuxième batteur retiré sur une line drive par le défenseur de la deuxième base. Double jeu, le défenseur de la deuxième base renvoie à temps vers le défenseur de la première base pour faire le retrait */
action { batter -> L4, runner1 -> 43 }

C’est bien un double jeu, mais on ne le compte pas comme un ‘GDP’ puisque la balle frappé n’a pas touché le sol.

Exemple 2: Avec un coureur sur la deuxième base, le batteur frappe une balle au sol vers le défenseur arrêt-court, qui rattrape la balle et touche le coureur qui tentait de rejoindre la troisième base, puis relance la balle au défenseur de la première base pour faire le retrait du batteur-coureur.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur avance sur un double au champ centre */
action { batter -> 2B8 }

/* Le deuxième frappeur est retiré sur un roulant vers l'arrêt-court. Double jeu : l'arrêt-court effectue un relais à temps vers le premier but pour le retrait. */
action { batter -> 6, runner2 -> 63 }

Ce n’est pas un ‘GDP’ puisque le coureur de la deuxième n’était pas forcé d’avancer.

Exemple 3: La première base est occupée et le batteur à deux ‘strike’ à son compte. Sur le lancer suivant, le coureur tente de voler la deuxième base. Le lancer est un troisième ‘strike’ ce qui signifie que le batteur est retiré sur un ‘strike out’.
Le receveur relance la balle au défenseur de la deuxième base à temps pour que ce défenseur puisse retirer le coureur quand il tente son vol de base.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur avance sur un « but sur balle ». */
action { batter -> BB }

/* Deuxième frappeur retiré sur trois prises. C'est un double jeu ; le receveur renvoie la balle au deuxième but à temps pour éliminer le coureur qui tentait de voler le deuxième but. */
action { batter -> KS, runner1 -> CS24 }

Clairement, il n’y a pas eu de frappe, ce n’est donc pas un ‘GDP’. Par contre, c’est bien un double jeu puisque les deux retraits sont effectués dans la même action et ceci sans erreurs.

Exemple : 4 Avec la deuxième et troisième base occupées, le troisième batteur frappe une balle qui touche le sol vers le défenseur arrêt-court, qui peut relayer à temps la balle vers le défenseur de la première base pour retirer le batteur coureur.
Les deux coureurs en profite pour avancer et le coureur le plus avancé tente de rejoindre le marbre.
Le défenseur de la première base relaie la balle au receveur à temps pour retirer ce coureur.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur frappe un double coup sur au champ gauche. */
action { batter -> 2B7

}

/* Le deuxième frappeur avance sur un « but sur balle ». */
action { batter -> BB }


/* Le frappeur envoie une balle au sol vers l'arrêt-court, qui la relaie à temps au premier but pour l'élimination. Les deux coureurs en profitent pour avancer d'un but. Le coureur qui atteint le troisième but tente de marquer, mais est éliminé par le receveur, aidé par le joueur de premier but. */
action { batter -> 63 , runner1 -> + , runner2 -> + 32 }

Dans cet exemple, la défense est crédité d’un double jeu mais, comme le coureur n’étais pas forcé d’avancé vers le marbre, on ne note pas un ‘GDP’. Chaque défenseur est crédité d’une participation à un double jeu.

Example 5.a: Avec la première base et la deuxième base occupée, le batteur frappe une balle au sol vers le défenseur de la troisième base, ce qui permet de retirer le coureur qui était obligé d’avancer, et complète le double jeu en renvoyant la balle à temps au défenseur de la deuxième base pour retirer le deuxième coureur.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier batteur avance sur 'Base on Ball' */
action { batter -> BB }

/* Le deuxième batteur avance sur un hit en champs gauche, le coureur en première base avance */
action { batter -> 1B7 , runner1 -> + }

/* Le troisième batteur frappe un balle au sol vers le défenseur de la troisième base qui touche sa base, puis relais a temps vers le défenseur de la deuxième base pour retirer le coureur arrivant de la première base */
action { batter -> GDP05 , runner1 -> 54 , runner2 -> 5 }

Le batteur se voit donc attribuer un ‘GDP’, même s’il n’a pas été retiré.

Example 5.b: Avec la première base et la deuxième base occupée, le batteur frappe une balle au sol vers le défenseur de la position arret-court qui relaye au défenseur de la deuxième base, ce qui permet de retirer le coureur arrivant de la première base qui était obligé d’avancer. Le défenseur de la deuxième base complète le double jeu en renvoyant la balle à temps au défenseur de la troisième base pour retirer le coureur le plus avancé. C’est donc un double jeu renversé

WBSC Transcription dans l'outil de scorage Outil
/* Le premier batteur avance sur 'Base on Ball' */
action { batter -> BB }

/* Le deuxième batteur avance sur un hit en champs gauche, le coureur en première base avance */
action { batter -> 1B7 , runner1 -> + }

/* Le troisième batteur frappe une balle au sol vers le défenseur arrêt court qui renvoie à temps la balle au défenseur de la deuxième base pour retirer le coureur venant de la première base. Ce défenseur relais la balle au défenseur de la troisième base qui touche le coureur arrivant de la deuxième base */
action { batter -> GDP06 , runner1 -> 64 , runner2 -> 45 }

Le batteur se voit donc aussi attribuer un ‘GDP’, même s’il n’a pas été retiré.

Example 6: Avec un coureur sur la première base, le batteur frappe une balle au sol qui est rattrapée par le défenseur arrêt-court et qui la relaye à temps au défenseur de la deuxième pour retirer le coureur.
A son tour, le défenseur de la deuxième base relaye cette balle au défenseur de la première base à temps pour le batteur-coureur.
Le scoreur attribut un double jeu à l’équipe défensive, note la participation des trois défenseurs qui ont au double jeu (Arrêt-court, deuxième base et première base) and attribubt un ‘GDP’ au batteur.

WBSC Transcription dans l'outil de scorage Outil
/* Le Premier patteur avance sur 'Base on Ball' */
action { batter -> BB }

/* Le deuxième batteur frappe une balle roulante sur l'arrêt court qui récupère la balle à temps au défenseur de la deuxième base pour retirer le coureur venant de la première base. Le défenseur de la deuxième base revoie a temps la balle au défenseur de la première base pour retirer le coureur batteur */
action { batter -> GDP43 , runner1 -> 64 }

Puisque la colonne ‘DP’ est utilisée pour enregsitrer à la fois les double et triple jeux, quand un triple jeu survient, la zone ‘NOTE’ doit contenir ‘La colonne DP de l’équipe xxx contient aussi un triple jeu’. Dans le cas d’un triple jeu, le symbôle reste identique et le batteur se voit attribuer un ‘GDP’ dans la zone des statistiques offensives.

Example 7: Les bases sont pleines. Le batteur frappe une ‘line drive’ qui est rattrapée par le défenseur de la troisième base.
Ce défenseur, après avoir rattrapé cette balle, touche sa base et retire le coureur qui venait de quitter la deuxième base. Il relaie alors la balle au défenseur de la deuxième base à temps pour retirer le coureur venant de la première base.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier batteur avance sur 'Base on Ball' */
action { batter -> BB }

/* Le deuxième batteur avance sur un hit en champs centre, le coureur en première base avance. */
action { batter -> 1B8 , runner1 -> + }

/* Le troisième batteur avance sur une erreur du défenseur de la première base après un relais du défenseur de la troisème base. Les deux coureurs avancent */
action { batter -> 4E3 , runner1 -> + , runner2 -> + }

/* Le quatrième batteur est retiré par le défenseur de la troisième base sur une line drive*. Le défenseur touche sa base et retire le coureur en troisième avant qu'il ne revienne sur sa base puis relaie à temps la balle vers le défenseur de la deuxième base pour retirer le coureur en deuxième avant qu'il ne touche sa base. */
action { batter -> L5 , runner1 -> + , runner2 -> 54 , runner3 -> 5 }

Ce jeu n’est pas un ‘GDP’ puisque la balle frappée n’a pas trouché le sol.

Example 8: Les bases sont pleines. Le batteur frappe une balle au sol qui est rattrapé par le défenseur de la troisième base. Il touche sa base, puis relaie la balle à temps au défenseur de la deuxième base qui touche sa base, qui ensuite relie aussi à temps la balle au défenseur de la première base pour le troisième retrait.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier batteur avance sur une erreur de rattrapée de fly de à l'arrêt court */
action { batter -> E6F }

/* Le deuxième batteur avance sur un hit en champs centre, le coureur en une avance */
action { batter -> 1B8 , runner1 -> + }

/* Le troisième batteur avance sur 'Base on Ball', tous les coureurs avancent */
action { batter -> BB , runner1 -> + , runner2 -> + }

/* Le quatrième batteur frappe une balle au sol vers le défenseur de la troisième base qui touche sa base et retire le coureur venant de la deuxième base, il relaie à temps vers le défenseur de la deuxième base. Pour retirer le coureur venant de la première base. Le défenseur de la deuxième relaie aussi à temps vers le défenseur de la première base pour retirer le batteur coureur. */
action { batter -> GDP43 , runner1 -> 54 , runner2 -> 5 }

Un ‘GDP’ est attribué contre le batteur.

Dans le cas de l’exemple 6, le double jeu est noté dans la zone défensive de l’équipe en défense comme ceci:

  • Avec une barre verticale dans la colonne PO pour les défenseurs qui ont fait le retrait;
  • Avec une barre verticale dans la colonne ‘A’ pour les défenseurs qui ont fait les assistances;
  • • Avec une seule barre verticale dans la colonne ‘DP’ pour chaque défenseur qui a participé au double jeu, sans se préoccuper de savoir s’ils ont fait un retrait, une assistance ou les deux.

Pour résumer, une assistance doit être créditée au défenseur arrêt-court, une assistance et un retrait au défenseur de la deuxième base et un retrait au défenseur de la première base. Toutefois, une seule participation à un double jeu sera créditée à ces trois joueurs.

Un double ou triple jeu sera aussi crédité pour l’équipe défensive, le nombre total de ce type jeu sera noté dans la case qui se situe juste à droite de la case contenant le terme ‘DOUBLE JEU’, case qui se situe à droite de la zone de statistique des lanceurs.
