Retrait automatique prévu par le règlement (“OBR”).

Il existe toute une série de retraits, considérés comme des retraits automatiques, listé dans les règles du baseball [OBR 9.09 (b) (c)]. Ce chapitre va parcourir toutes ces règles, en les illustrant par des exemples si nécessaire. On utilise la notation ‘OBR’ pour tous ces retraits. Il y en a quatorze au total.

Afin de clarifier l’action qui à mener à ces retraits automatiques, le numéro de l’action doit être notée à l’extérieur du cercle de retrait en haut et sur le côté droit.

Si le scoreur à un doute sur une action qui a entrainé un retrait, le scoreur doit demander à l’arbitre la cause de ce retrait à la fin du match (ou de la manche si possible).

NOTE: Certaines actions sur le terrain peuvent ne pas être couvertes exactement par ces quatorze règles. Dans ce cas, on doit noter l’action avec la règle dont la définition est la plus proche de l’action, et une description de l’action doit est faite dans la zone ‘Note’ de la feuille de scorage (deuxième feuille de la feuille de scorage).

1) Batteur retiré pour une frappe illégale[OBR 9.09(b)(2)].

WBSC Transcription dans l'outil de scorage Outil
/* Batteur retiré sur une frappe illégale */
action { batter -> OBR1-2 }

Pour mémoire, l’arbitre déclare une frappe illégale quand :

  • "Il frappe une balle avec un ou deux pieds touchant le sol complètement à l’extérieur du rectangle du batteur" [OBR 6.03(a)(1)];

  • "Il passe d’un rectangle de batteur à l’autre alors que le lanceur est en position de lancer" [OBR 6.03(a)(3)];

  • "Il utilise ou tente d’utiliser une batte qui, selon l’arbitre, a été modifiée de quelque façon que ce soit pour améliorer la distance de frappe ou causer des réactions inhabituelles sur la balle" [OBR 6.03(a)(4)] . "Un batteur sera considéré comme ayant utilisé ou ayant tenté d’utiliser une batte modifiée s’il en amène une dans le rectangle du batteur" [OBR 6.03(a)(4) Comment].

Dans le cas d’un ‘OBR’ 1, le retrait sera crédité au receveur, ce qui explique le ‘2’ noté dans le cercle indiquant le retrait.

2) Batteur retiré pour avoir effectué un amorti dans la zone des fausses balles pour son troisième ‘strike’ [OBR 5.09(a)(4), 9.09(b)(3)]. Dans ce cas, on doit noter ‘OBR KS’ et, en accord avec les règles du baseball, un ‘strike out’ doit être crédité au lanceur. Le retrait doit être porté au crédit du receveur.

WBSC Transcription dans l'outil de scorage Outil
/* Batteur retiré pour un bunt dans la zone des fausses balles pour son troisième strike */
action { batter -> OBRKS-2 }

Pour mémoire, comme c’est un ‘Strike Out’, il ne faut oublier de noter le nombre courant de ‘strike out’ du lanceur.

Cette règle s’applique aussi pour le retrait d’un batteur quand :

  • " Un troisième strike n’est pas attrapé par le receveur quand la première base est occupée avant deux retraits ” (OBR 5.09(a)(3)].

  • “ Il tente de frapper un troisième strike et que la balle le touche ” [OBR5.09(a)(6)].

  • “ Avec deux retraits et deux strikes au compte du batteur, si le coureur en troisième base, essaye de voler le marbre lors d’un lancer régulier et que la balle le touche dans la zone de strike, l’arbitre annonce « troisième strike », le batteur est retiré et le point n’est pas marqué ; avant deux retraits l’arbitre annonce « troisième strike » la balle est morte et le point compte ”. [OBR 5.09(a)(14)]

  • “ Quand, après un troisième strike, le batteur gène le receveur dans son action de relancer la balle dans le champ ". [OBR 6.01(a)(1)]

3) Batteur éliminé pour avoir touché la balle frappée. Il faut noter qu’un batteur est retiré uniquement s’il est touché par la balle dans le territoire des bonnes balles quand il est en dehors de sa boite et avant que la balle ne soit touchée par un défenseur. Dans les autre cas, l’arbitre appel un ‘foul ball’ [OBR 5.09 (a) (7), 9.09 (b) (4)]. Un batteur est aussi retiré si Après avoir frappé ou amorti la balle en territoire des fausses balles, il fait volontairement dévier la balle de sa course d’une façon quelconque alors qu’il court vers la première base [OBR5.09(a)(9)] ou “ Après avoir frappé ou amorti une balle en territoire des bonnes balles, sa batte retouche la balle dans ce territoire " [OBR 5.09(a)(8)].

WBSC Transcription dans l'outil de scorage Outil
/* Batteur retiré pour avoir touché la balle qu'il vient de frapper */
action { batter -> OBR3-2 }

4) Batteur éliminé pour interférence avec le receveur [OBR 9.09(b)(5)]. L’arbitre appellera une interférence quand le batteur-coureur " gêne le jeu du receveur quand celui-ci attrape ou relaie la balle en sortant du rectangle du batteur ou en l’empêchant autrement de compléter son jeu au marbre ” [OBR 6.03(a)(3)].

WBSC Transcription dans l'outil de scorage Outil
/* Batteur retiré pour interférence avec le receveur */
action { batter -> OBR4-2 }

5) Batteur éliminé pour avoir oublié son tour de frappe. Dans ce cas, un batteur qui ne passe pas au bâton alors que c’est son tour est retiré si l’équipe opposé fait appel avant un nouveau jeu [OBR 6.03(b), 9.03(d) et 9.09(b)(6)].
EXCEPTION: Si un batteur irrégulier est retiré dans l’action liée à sa frappe, et que l’équipe opposée fait appel, alors le batteur régulier est déclaré retiré, le retrait enregistrer comme un retrait dans le champ, et toutes les assistances doivent être comptée.

WBSC Transcription dans l'outil de scorage Outil
/* Batteur retiré pour ne pas avoir respecté l'ordre au baton */
action { batter -> OBR5-2 }
/* Batteur retiré pour ne pas avoir respecté l'ordre au baton avec assistance */
action { batter -> OBR5-53 }

6) Batteur éliminé pour refus d’avancer en 1ère base après un ‘base on ball’, un ‘hit by pitch’ ou après une interférence du receveur [OBR 9.09(b)(7) and 9.14(c)]. " Si le coureur de la troisième base refuse d’avancer et de toucher le marbre dans un délai raisonnable, l’arbitre doit annuler le point ; le joueur est retiré sur décision de l’arbitre et la rencontre continue. Si, après deux retraits le batteur coureur refuse d’avancer et de toucher la première base, l’arbitre doit annuler le point,>[OBR 5.08(b) penalty].

WBSC Transcription dans l'outil de scorage Outil
/* Batteur retiré pour avoir refusé de toucher la première base après un 'base on ball', un 'hit by pith' ou après une interférence du catcheur, */
action { batter -> OBR6-2 }

7) Coureur éliminé pour avoir refusé d’avancer de la troisième base vers le marbre (dans le cas où il est forcé) pour le point gagnant [OBR 9.09(b)(8)]. Pour les règles 7 et 8 du baseball OBR rule 5.08(b), les pénalités disent : Quand le point gagnant est marqué, “ Si le coureur de la troisième base refuse d’avancer et de toucher la plaque de but dans un délai raisonnable, l’arbitre doit annuler le point ; le joueur est retiré sur décision de l’arbitre et la rencontre continue ".

WBSC Transcription dans l'outil de scorage outil
/* Le batteur frappe un triple hit dans le champ droit */
action { batter -> 3B9 }

/* coureur retiré pour avoir refusé de marquer le point alors qu'il est forcé d'avancer */
action { runner3 -> OBR7-2 }

8) Batteur éliminé sur ‘Infield Fly’ non réceptionné. Le retrait est crédité au défenseur qui, d’après l’opinion du scoreur, aurait dû effectuer le rattrapé [OBR 5.09(a)(5), 9.09(c)(1)]. On utilise aussi l’OBR 8 dans le cas de la règle 5.09(a)(12).

WBSC Transcription dans l'outil de scorage Outil
/* Batteur retiré sur un infield fly qui n'a pas été rattrapé de volé */
action { runner3 -> OBR8-5 }

9) Coureur éliminé pour avoir touché une balle frappée dans la zone des bonne balles (Incluant un ‘Infield Fly’ s’il n’est pas en contact avec une base) [OBR9.09(c)(2)]. Le retrait est crédité au défenseur qui est le plus proche de l’endroit où le coureur se fait toucher par la balle. Le batteur doit être crédité d’un ‘hit’ même s’il y a deux retraits, à condition qu’un ‘Infied fly’ ne soit pas appelé. Il faut noter que la balle a déjà dépassé un défenseur du champ intérieur (autre que le lanceur), le coureur n’est pas retiré et la balle reste en jeu. [OBR 5.09(b)(7) et 6.01(a)(11)].

WBSC Transcription dans l'outil de scorage Outil
/* Le batteur frappe un simple dans le champ gauche */
action { batter -> 1B7 }

/* Le deuxième batteur frappe une balle en direction de la deuxième qui va toucher le coureur venant de la première base */
action { batter -> 1B4 , runner1 -> OBR9-4 }

10) Coureur éliminé pour être sorti de son couloir de course pour éviter d’être touché. Le retrait est crédité au défenseur le plus prochce de l’endroit où le coureur est sorti du couloir. Les assistances des autres défenseurs doivent être notées comme d’habitude [OBR 5.09(b)(1), 9.09(c)(3)]. Avec un coureur sur la première base, le lanceur lance une balle qui est renvoyé par le receveur après le lancer. Le lanceur relaye la balle au défenseur de la première base, tandis que le coureur tente de rejoindre la deuxième base, le défenseur de première relaye la balle au défenseur de la deuxième base, le coureur est alors retiré pour être sortie de son couloir pour éviter le défenseur de la deuxième base.

WBSC Transcription dans l'outil de scorage Outil
/* le batteur avance sur un 'base on ball' */
action { batter -> BB }

/* le coureur éliminé pour être sorti de son couloir de course pour éviter d’être touché */
action { runner1 -> OBR10-134 }

11) Coureur éliminé pour avoir doublé un autre coureur. Le retrait est crédité au défenseur qui est le plus proche de l’endroit ou s’est fait le dépassement [OBR 5.09(b)(9), 9.09(c)(4)]. Avec la première base et la deuxième base occupée, le batteur frappe un ‘hit’ dans le champ. Le coureur le plus proche du marbre reste proche sa base, craignant que la balle ne soit rattrapée de voler. Le coureur en première base effectue une course rapide et dépasse son équipier au niveau de la deuxième base.

WBSC Transcription dans l'outil de scorage Outil
/* le batteur avance sur un 'base on ball' */
action { batter -> BB }

/* Le deucxième batteur frappe une balle dans le champs gauche, les coureurs avancent */
action { batter -> 1B7 , runner1 -> + }

/* Le troisième frappeur frappe un simple dans le champ gauche, Le coureur en première base avance en deuxième et est éliminé car il double le coureur en troisième base qui n'a pas bougé. */
action { batter -> 1B7 , runner1 -> + OBR11-6 , runner2 -> + }

12) Coureur éliminé pour course à l’envers sur les bases. Le retrait est crédité au défenseur qui protège la base au moment où il commence sa course à l’envers [OBR 5.09(b)(10), 9.09(c)(5)]. Un coureur en deuxième base, avec un lanceur prêt à lancer, le coureur cours vers la première base pour mettre la confusion dans la défense.

WBSC Transcription dans l'outil de scorage Outil
/* Le batteur frappe un double dans le champ gauche */
action { batter -> 2B8 }

/* Coureur éliminé pour course à l’envers sur les bases */
action { runner2 -> OBR12-4 }

13) Coureur éliminé pour avoir interféré avec un défenseur. Lorsqu’un coureur interfère avec un défenseur, le coureur est retiré et le défenseur se voit attribué le retrait, sauf si ce défenseur était en train de relayé une balle. Dans ce cas, on attribue une assistance au défenseur, et un retrait pour le défenseur qui devait recevoir la balle [OBR 5.09(b)(3), 6.01(a)(6), 6.01(a)(19), 09.09(c)(6)]. Le batteur-coureur, qui frappe un ‘hit’ dans le champ droit, tente de prendre la deuxième base et bouscule le défenseur de la deuxième base qui était assisté par le défenseur du champ droit.

WBSC Transcription dans l'outil de scorage Tool
/* Le batteur frappe un hit dans le champ droit, puis bouscule le défenseur de la deuxième base qui était assisté par le défenseur du champ droit */
action { batter -> 1B9 OBR13-94 }

Avec un coureur sur la première base, le batteur-coureur frappe un ‘hit’ simple sur le champ droit. Le coureur qui avance interfère avec le défenseur de la deuxième base qui voulait relayer la balle au défenseur de la première base pour retirer le batteur-coureur. Dans ce cas, on crédite une assistance aux défenseurs du champs droit et de la deuxième base, et un retrait au défenseur de la première base.

WBSC Transcription dans l'outil de scorage Outil
/* Le batteur frappe un hit dans le champ droit, puis bouscule le défenseur de la deuxième base qui était assisté par le défenseur du champ droit. */
action { batter -> 1B9 OBR13-943 }

Cette règle s’applique aussi pour le cas où le batteur-coureur, lorsqu’il parcours la dernière moitié de la distance entre le marbre et la première base, interfère avec un défenseur [OBR 5.09(a)(11)].

14) Batteur-coureur éliminé pour cause d’interférence d’un coureur sur base. On crédite un retrait au défenseur de la première base. Si le défenseur qui a été gêné était en train de relayé la balle, alors on lui accorde une assistance [OBR 5.09(a)(13), 6.01(a)(7), 9.09(c)(7)]. Avec une balle frappée au sol vers la deuxième base, le défenseur de la deuxième base assiste le défenseur de l’arrêt court pour retirer le coureur. Quand ce défenseur relaye la balle vers le défenseur de première base pour faire un double jeu, il est gêné par le coureur. L’arbitre retire le batteur-coureur pour interférence à cause de l’interférence du coureur. On attribue donc une assistance au défenseur de l’arrêt-court même si celui n’a pas relayé la balle vers la première base.

WBSC Transcription dans l'outil de scorage Outil
/* Le batteur frappe un simple dans le champ centre */
action { batter -> 1B8 }

/* Le deuxième batteur interfère avec le coureur */
action { batter -> OBR14-63 , runner1 -> 46 }

Il est possible d’avoir un OBR 13 et OBR 14 dans la même action, comme dans l’exemple décrit ci-dessous::

Avec moins de deux retraits et un coureur sur la première base, le batteur frappe un ‘hit’ sur le défenseur de la deuxième base, mais il rattrape la balle à temps pour effectuer un double jeu. Comme il attends pour assister le défenseur arrêt-court, qui vient couvrir la deuxième base il est bousculé par le coureur. L’arbitre retire le coureur et le batteur-coureur pour interférence .

WBSC Transcription dans l'outil de scorage Outil
/* Le batteur frappe un hit dans le champ droit */
action { batter -> 1B9 }

/* Le batteur et le coureur sont retirés */
action { batter -> OBR14-63 , runner1 -> OBR13-46 }

Le scoreur ne doit pas attribuer un ‘GDP’ à un batteur si il est retiré à cause d’une interférence faite par un coureur. [OBR 9.02(a)(17) Comment].
