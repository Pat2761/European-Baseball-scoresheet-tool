Matchs terminés en raison de l'écart de points

Une partie peut être interrompue en raison de l'écart de points entre les deux équipes.

Dans le cas où un match interrompu selon les conditions susmentionnées est néanmoins considéré comme un match réglementaire, toutes les dispositions relatives aux points victorieux et à la valeur des coups sûrs s'appliquent.
