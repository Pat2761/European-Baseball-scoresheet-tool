Points mérités.

Conformément à la règle 9.16 des OBR, un point mérité (ER) est comptabilisé lorsque, avec moins de trois occasions de retrait, toutes les progressions sur les buts du joueur ayant atteint le marbre peuvent être attribuées au lanceur. Un point mérité est comptabilisé lorsque ces progressions résultent des situations suivantes :

  • Batteur-coureur: coups sûrs, choix défensifs (balles occupées), bases sur balles (y compris les bases sur balles intentionnels), frappeurs atteints par un lancer et, en l'absence d'occasion de jeu défensif, progression en première base sur un retrait au bâton combiné à un lancer fou.
  • Coureurs: toutes les progressions résultant de coups sûrs, de bases volés, d'amortis-sacrifices, de sacrifices flys, de retraits, de choix défensifs, de feintes illégales (balks), de lancers fous, d'interférences du receveur et d'avancées forcées consécutives à l'attribution de la première base au batteur.
À cet égard, il convient de noter que, pour un point mérité, le petit losange situé au centre de chaque case formé par les traits tracés au fur et à mesure que le coureur progresse sur les bases doit être rempli.
Si le point n'est pas mérité, le losange reste vide.
Si le point n'est PAS mérité contre l'équipe, une croix doit être tracée à l'intérieur du losange.

Avant d'aborder la question complexe des points mérités, il convient d'examiner ce que l'on entend par « occasion défensive ».

Une « occasion de jeu défensif » se définit comme tout moment où, selon l’avis du scoreur, la défense a la possibilité d’effectuer un retrait, que cette occasion ait été saisie avec succès ou manquée en raison d’une erreur.

Les occasions de jeu défensif incluent: les retraits (putouts), toutes les erreurs décisives (y compris celles ayant permis au batteur auteur d'un coup sûr de sacrifice d'atteindre la première base en toute sécurité), ainsi que toutes les arrivées sur base de batteurs-coureurs enregistrées sous les codes « K PB », « OB » et, dans des cas précis, « K WP » (selon que la situation implique KL ou KS combiné à PB ou WP).

Si le lanceur n'est pas tenu responsable des points marqués après la troisième occasion de jeu défensif, c'est parce que, si la défense avait su tirer parti de chacune de ces opportunités, elle aurait réalisé trois retraits et cette phase de la manche aurait pris fin.

Dans l' Exemple 1 Dans la situation présente, la défense a déjà eu trois occasions d'intervenir : deux retraits ont été effectués et un troisième coureur a atteint sa base à la faveur d'une erreur.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur est retiré sur un strike out. */
action { batter -> KS }

/* Le batteur suivant frappe la balle en direction de l'arrêt-court, qui la relaie pour éliminer le batteur-coureur. */
action { batter -> 63 }

/* Le frappeur suivant atteint la première base sur une erreur. */
action { batter -> E6T }

Une balle non rattrapée considérée comme une erreur doit également être considérée comme une occasion de jeu défensif, puisque le batteur aurait pu être éliminé. Il existe par ailleurs d'autres situations où une telle occasion peut se présenter sans pour autant aboutir à une élimination ou à une erreur défensive.

En général, lorsque deux occasions de réaliser un retrait se présentent pour un même joueur, une seule est comptabilisée, car un joueur ne peut être retiré qu'une seule fois. Exemple 2 montre deux actions défensives : une erreur du receveur et une balle en hauteur captée par le joueur de champ droit.

WBSC Transcription dans l'outil de scorage Outil
/* Le batteur aurait dû être éliminé sur une pop. */
action { batter -> EF2 }

/* Le batteur est retiré sur une fly frappée vers le champ droit. */
action { batter -> F9 }

ATTENTION: Ces exemples illustrent des situations où deux occasions d'intervention se présentent pour un même joueur, mais où une seule d'entre elles est comptabilisée.

Exemple 3: Comme le batteur-coureur aurait été retiré sans l'erreur, il n'y avait aucune possibilité de le prendre en Pick-off.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un simple sur le lanceur. */
action { batter -> 1B1 }

/* Le batteur suivant frappe la balle en direction de l'arrêt-court, qui la relaie en première base. Le joueur de champ commet une erreur. */
action { batter -> 6E3 , runner -> + }

/* Le coureur est retiré sur un pick off. */
action { batter -> PO13 }

Exemple 4: Il y a deux occasions de jeu défensif concernant le coureur retiré en deuxième base. Il convient toutefois de noter que si ce coureur avait été retiré en première base au lieu d'atteindre la base en toute sécurité grâce à une erreur, la défense aurait également retiré le frappeur suivant, réalisant ainsi deux retraits au total.

WBSC Transcription dans l'outil de scorage Outil
/* Le batteur atteint la première base sur une erreur. */
action { batter -> E6F }

/* Le batteur suivant frappe la balle en direction de l'arrêt-court, qui la relaie pour éliminer le coureur. */
action { batter -> O6 , runner -> 64 }

Par conséquent, dans ce genre de situation, deux occasions de jeu défensif sont comptabilisées. Tout point marqué par le coureur ayant atteint sa base sur une action impliquant un joueur déjà sur base ne serait pas considéré comme un point mérité.

IMPORTANT: Si, au cours d'une manche, la défense fait face à trois occasions de jeu défensif, aucun point mérité n'est imputé au lanceur. La raison de cette règle est assez simple à comprendre : si ces trois occasions s'étaient soldées par trois retraits, la manche aurait pris fin et l'équipe en attaque n'aurait plus pu marquer de points. En revanche, si la manche se poursuit, le fait que ces occasions ne se soient pas concrétisées par des retraits relève de la seule responsabilité de la défense ; c'est pourquoi aucun point mérité supplémentaire n'est porté au compte du lanceur.

Un batteur est automatiquement déclaré retiré lorsque, avec moins de deux retraits et la première base occupée, le troisième *strike* survient sur un lancer fou (*wild pitch*). Si la première base est libre ou s'il y a deux retraits, le batteur-coureur peut tenter de l'atteindre. S'il y parvient, le symbole à utiliser pour noter sa progression vers la première base est « KS1 WP » ; bien qu'il ne s'agisse généralement pas d'une occasion de jeu défensif, ce cas fait exception à la règle, comme c'est parfois le cas.

En effet, si la première base est libre parce que le coureur a profité d'une erreur ou d'une balle passée pour avancer, la situation « KS1 WP » (retrait sur prises, balle échappée/fole) est alors considérée comme une occasion de jeu défensif. Cela ressort clairement du fait qu'en l'absence d'erreur ou de balle passée, la première base serait resté occupée et le batteur aurait, par conséquent, été automatiquement déclaré retiré. Par conséquent, les points marqués par un batteur devenu coureur à la suite d'une telle situation ne peuvent être comptabilisés comme des points mérités.

Exemple 5: Alors qu'il n'y a aucun retrait et qu'un coureur occupe la première base, le huitième frappeur de l'alignement frappe la balle en direction du champ droit ; le défenseur ne parvient pas à la saisir, et le frappeur-coureur en profite pour avancer d'une base. Le frappeur suivant s'élance sur le troisième prises qui est également un mauvais lancer et parvient à atteindre la première base en toute sécurité, tandis que les autres coureurs avancent d'une base sur ce mauvais lancer.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur atteint la première base sur un base sur balles. */
action { batter -> BB }

/* Le batteur suivant frappe la balle vers le champ droit et avance d'une base sur une erreur. */
action { batter -> 1B9 e9 , runner1 -> ++ }

/* Le batteur suivant atteint la première base sur une troisième prise relachée, et les coureurs avancent. */
action { batter -> KSWP , runner2 -> wp , runner3 -> wp earned }

Exemple 6: Si le défenseur du champ droit de l'exemple 5 n'avait pas commis d'erreur, le neuvième frappeur aurait trouvé la première but occupée et aurait été retiré sur prise, tandis que les coureurs auraient avancé d'une base sur le mauvais lancer.
« KS1 WP » dans l'exemple 5 correspond donc à une occasion de jeu sur le terrain.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur atteint la première base sur un base sur balles. */
action { batter -> BB }

/* Le batteur suivant frappe la balle vers le champ droit et avance d'une base sur une erreur. */
action { batter -> 1B9 , runner1 -> ++ }

/* Le batteur suivant atteint la première base sur une troisième prise relaché, et les coureurs avancent. */
action { batter -> KS , runner1 -> wp , runner3 -> WP earned }

Exemple 7: Une tentative ratée de prendre le coureur avec pick off en première base permet à celui-ci d'avancer en deuxième base et offre au frappeur l'occasion d'atteindre la première base sur un « KS1 WP ».

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur atteint la première base sur un base sur balles. */
action { batter -> BB }

/* Le coureur aurait dû être éliminé en tentative de pick-off, mais il a progressé sur une erreur. */
action { runner -> POe1T }

/* Sur un troisième retrait sur prise relachée, le frappeur atteint la * première base et le coureur avance sur le mauvais lancer. */
action { batter -> KSWP , runner2 -> wp }

Exemple 8: Sans l’erreur du lanceur, la première base aurait été occupée et, par conséquent, automatiquement interdit au batteur.
Le « KS1 WP » constitue donc une opportunité de jeu défensif.

WBSC Transcription dans l'outil de scorage Outil
/* The first batter reaches first base on a base on balls. */
action { batter -> BB }

/* Sur un troisième retrait sur prise relachée, le frappeur atteint la première base et le coureur progresse sur le mauvais lancer. */
action { batter -> KS , runner1 -> WP }

Exemple 9: Après s'être élancé sur le troisième prises, le batteur-coureur parvient à atteindre la première base grâce à une balle échappée (*passed ball*) survenue plus tôt. La séquence « KS1 WP » constitue donc une occasion de jeu défensif.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur atteint la première base sur un hit by pitch. */
action { batter -> HP }

/* Le coureur avance sur une balle passée. */
action { runner1 -> PB }

/* Troisième prise relachée : le batteur atteint la première base et le coureur progresse sur le mauvais lancer. */
action { batter -> KSWP , runner -> wp }

Exemple 10: Sur les trois points produits grâce au homerun, seuls le premier et le dernier sont considérés comme mérités, car le deuxième frappeur a atteint la première base sur un « KS1 WP » (retrait sur des prises, balle relachée par le receveur) consécutif à une balle relachéeprécédente. Le « KS1 WP » constitue donc une occasion de jeu défensif.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur atteint la première base sur un hit by pitch. */
action { batter -> HP }

/* Le coureur avance sur une balle relachée. */
action { runner1 -> PB }

/* Troisième prise relachée : le batteur atteint la première base et le coureur progresse sur le mauvais lancer. */
action { batter -> KSWP , runner -> wp }

/* Le batteur suivant frappe un home run et tout le monde marque un point. */
action { batter -> HR8 earned , runner -> +++ , runner -> + earned }

IMPORTANT: Toutes les progressions résultant d'un retrait sur des prises combiné à un mauvais lancer (KS1 WP) sont considérées comme régulières, puisqu'elles ont eu lieu sur un mauvais lancer.
