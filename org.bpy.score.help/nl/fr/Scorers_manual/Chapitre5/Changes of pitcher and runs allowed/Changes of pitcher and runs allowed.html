Changements de lanceur et points mérités.

La situation se complique lorsqu'il y a un ou plusieurs changements de lanceur. Le règlement stipule : Lorsqu’il y a changement de lanceur au cours d’une manche, le scoreur officiel ne doit pas rendre le lanceur de relève responsable du point (mérité ou non) marqué par un coureur qui était sur une base au moment de l’entrée en jeu du lanceur de relève, ni d’aucun point marqué par tout coureur qui atteint une base sur un choix défensif permettant de retirer un coureur laissé sur une base par le lanceur précédent [OBR 9.16(g)].

Examinons cela de plus près.

Lors d'un changement de lanceur, les coureurs encore sur les bases sont imputés au lanceur qui les y a placés ; ce dernier est également tenu pour responsable de tout point qu'ils viendraient à marquer. Des difficultés d'interprétation surviennent toutefois concernant le second volet de cette règle. Cette disposition vise les actions d'un coureur (en l'occurrence, le batteur-coureur) entraînant le retrait d'un coureur précédent, lequel avait été placé sur base par le lanceur sortant.

Cela peut être observé plus clairement dans les exemples suivants.

Exemple 25: Le lanceur sortant laisse un coureur sur les bases lorsqu'il est relevé. Le frappeur suivant réussit un simple vers le champ droit et le coureur précédent marque.
En règle générale, et sans exception, les coureurs laissés sur les bases par un lanceur sont attribués au lanceur sortant.
C'est pour cette raison que le point est attribué au premier lanceur.

/* Le frappeur frappe un simple vers le champ centre. */

/* Remplacement du lanceur */
substitution hometeam { player 1 replaceBy "WILLIS Bruce" shirtNumber= 32 at 1 }

/* Le batteur frappe un simple vers le champ droit et le coureur marque. */
action { batter -> 1B9 , runner1 -> +++ earned }

Exemple 26: Le premier lanceur laisse un coureur sur les bases, et celui-ci est retiré après le remplacement du lanceur, à la suite d'une action de jeu normale impliquant une balle frappée.
Étant donné que le premier lanceur a laissé un coureur sur les bases, un point doit lui être imputé.
Nous avons ici les deux conditions fondamentales : une balle en jeu et le retrait d'un coureur placé sur base par le premier lanceur.
Le point est donc imputé au premier lanceur.

L'OBR stipule dans la règle 9.16(i) que Lorsqu'il y a changement de lanceur au cours d'une manche, le lanceur de relève ne doit pas bénéficier des précédentes opportunités de retraits non réalisées, pour déterminer les points mérités.

Rule 9.16(i) Commentaire: Il est dans l'intention de la règle 9.16(i) que soient portés au compte des lanceurs de relève les points mérités dont ils sont seuls responsables. Dans certains cas, les points attribués comme mérités contre le lanceur de relève, peuvent être accordés comme non mérités contre l’équipe.

Pour clarifier le sens de cette remarque, examinons l'exemple suivant.:

Exemple 34: Le premier batteur frappe une fly et est retiré par le champ gauche.
Le batteur suivant atteint la deuxième base en toute sécurité grâce à une erreur de réception du joueur de champ centre.
Le troisième frappeur frappe un simple vers le champ droit, envoyant le coureur au troisième base.
Le quatrième frappeur frappe unsacrifice fly qui permet au coureur posté en troisième base de marquer le premier point (le coureur en première base reste sur place).
Après un changement de lanceur, le cinquième frappeur réussit un homerun qui permet de marquer deux points.
Le premier lanceur est crédité de deux points non mérités (trois occasions de jeu défensif s'étaient présentées au moment où le coup de circuit a été frappé : « F7 », « E8F » et « SF8 »)..
Le deuxième lanceur est crédité d'un point mérité (seules deux occasions de jeu défensif ont été transmises par le lanceur précédent : « F7 » et « SF8 »).
Trois points sont imputé à l'équipe, dont aucun n'est un point mérité, car elle a eu trois occasions de jeu défensif : « F7 », « E8F » et « SF8 ».
Cet exemple montre que le troisième point est un point non mérité pour l'équipe, mais un point mérité pour le lanceur.

/* Le batteur suivant frappe un coup de circuit, tous les coureurs avancent. */
action { batter -> HR7 unEarnedForTeam , runner1 -> +++ unEarnedForTeam , runner2 -> ++ , runner3 -> + }

/* Le batteur suivant est retiré sur des prises. */
action { batter -> KL }

Aucun de ces deux points n'est toutefois considéré comme mérité : pour le premier, une occasion de jeu défensif avait été transférée depuis le premier batteur, et pour le second, trois occasions de jeu défensif s'étaient déjà produites.

Les deux autres points sont imputés au deuxième lanceur ; ils sont considérés comme mérités à son encontre, mais pas à celle de l'équipe, étant donné que le lanceur n'avait eu à traiter que deux occasions de jeu défensif.

En ce qui concerne les occasions de jeu en défensive, il convient de noter qu'une tentative de double retrait offre deux opportunités au sein d'une même action, pouvant se solder soit par deux retraits, soit par un retrait et une erreur.

Toutefois, si une seule élimination est réalisée et qu'une autre tentative d'élimination échoue sans qu'il y ait eu d'erreur, une seule occasion de jeu défensif a eu lieu.

Pour conclure ce chapitre sur les points mérités, nous examinerons de plus près la question des avancées réglementaires et non réglementaires.

Un coureur sur base n'est pas statique et peut participer à une action de jeu. Lorsqu'un coureur n'aurait pas dû se trouver sur base ou n'aurait pas dû atteindre cette position (en raison d'une erreur ou d'une balle échappée), aucune action qu'il a effectuée ne doit être prise en compte pour le calcul des points mérités.

Exemple 42: Le coureur situé en deuxième base n'aurait pas pu avancer si le jeu s'était déroulé correctement, par conséquent, aux fins du calcul des points mérités, il doit être considéré comme se trouvant en première base.

WBSC Transcription dans l'outil de scorage Outil
/* Le batteur frappe un simple vers le champ gauche et profite de l'erreur pour gagner une base supplémentaire. */
action { batter -> 1B7 e7 }

Exemple 43: Le premier frappeur envoie la balle au champ droit et, grâce à une erreur du défenseur, atteint la troisième base. Le deuxième frappeur obtient un base on balls et vole ensuite la deuxième base. Le troisième frappeur frappe la balle au champ gauche, permettant aux deux coureurs de marquer.
Jusqu'à ce stade, le premier point est considéré comme mérité, mais pas le second, en effet, sans l'erreur du joueur de champ extérieur, le coureur de tête serait resté sur la deuxième base privant ainsi l'autre coureur de toute possibilité de vol de base et le coup sûr du troisième batteur n'aurait permis de marquer qu'au premier coureur, tandis que le second se serait arrêté en troisième base.

WBSC Transcription dans l'outil de scorage Outil
/* Le batteur frappe un simple vers le champ droit et profite de l'erreur pour avancer de deux bases supplémentaires. */
action { batter -> 1B9 e9+ }

/* Le frappeur atteint la première base sur un base on balls. */
action { batter -> BB }

/* Le coureur au premier but vole une base. */
action { runner1 -> SB }

/* Le frappeur réussit un simple vers le champ gauche et les deux coureurs marquent. */
action { batter -> 1B7 , runner2 -> ++ , runner3 -> + earned }

Exemple 44: Le premier batteur obtient un base on balls et atteint la deuxième base à la suite d'une erreur commise par le défenseur de la première base alors qu'il tentait de le retirer par un pick off. Le deuxième batteur atteint la première base sur un mauvais lancer après s'être élancé sur la troisième prises, tandis que le coureur atteint la troisième base. Le troisième batteur frappe un homerun. Les premier et troisième points sont des points mérités, mais pas le deuxième ; en effet, sans l'erreur défensive commise sur le premier coureur, la première base aurait été occupé et le deuxième batteur aurait été déclaré retiré en vertu de la règle 5.09(a)(3) du règlement officiel du baseball (OBR).

/* Le coureur atteint la deuxième base sur une tentative de retrait par relais du lanceur ratée. */
action { runner1 -> PO1e3 }

/* Le batteur atteint la première base sur un troisième prises échappé. */
action { batter -> KSWP , runner2 -> wp }

/* Le batteur frappe un homerun. */
action { batter -> HR7 earned , runner1 -> +++ , runner3 -> + earned }

IMPORTANT: Il ressort des deux exemples précédents qu'une avance illégale prise par un coureur précédent peut affecter la légalité d'une action ultérieure.

Exemple 45: Alors qu'un coureur occupe la deuxième base à la suite d'une erreur, un coup sûr en direction du champ centre lui permet de marquer, tandis que le batteur-coureur atteint la deuxième base pendant le relais vers le marbre.
Si l'action avait été réglementaire, le premier coureur ne se serait pas trouvé là où il était ; par conséquent, le défenseur n'aurait pas effectué de lancer vers le marbre et le frappeur serait resté en première base.
Sur le coup suivant, un nouveau point est marqué. Pour l'instant, il est considéré comme non mérité, car le coureur, après avoir progressé de deux bases, se serait retrouvé en troisième base.
Nous recommandons donc de reconstituer soigneusement l'action pour déterminer si une progression est réglementaire ou non. À cet égard, il peut être utile de reconstituer une manche fictive ne comportant que des progressions réglementaires, en excluant toutes celles résultant d'erreurs ou de balles échappées.

WBSC Transcription dans l'outil de scorage Outil
/* Le batteur atteint la première base sur une erreur commise sur une fly et gagne une base supplémentaire sur l'action. */
action { batter -> E9F+ }

/* Le batteur frappe un simple vers le champ centre et profite du relais pour atteindre la deuxième base ; le coureur marque. */
action { batter -> 1B8 T82 , runner2 -> ++ }

/* Le batteur suivant est retiré sur des prises. */
action { batter -> KS }

/* Le batteur frappe un simple vers le champ gauche et le coureur marque. */
action { batter -> 1B7 , runner2 -> ++ }

Exemple 46: Dans cette situation, nous voyons l'action telle qu'elle s'est déroulée. Nous avons une indication de ce qui se serait passé si le jeu avait été régulier* : le deuxième frappeur n'aurait pas encore marqué de point, mais se serait arrêté en troisième base.
Grâce à cette méthode, on peut clairement constater que si un coureur avait marqué sur une action régulière, le point correspondant dans l'action réelle serait considéré comme mérité, même si l'action elle-même avait été irrégulière. Dans le cas contraire, un point effectivement marqué serait considéré comme non mérité.
