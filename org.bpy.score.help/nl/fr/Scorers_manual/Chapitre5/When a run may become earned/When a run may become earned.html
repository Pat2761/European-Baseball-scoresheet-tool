Quand un point peut être considéré comme mérité.

Il arrive qu'un point ne soit pas considéré comme « mérité » au moment où il est marqué, mais qu'il le devienne au cours de l'action qui suit, sous certaines conditions.

Pour mieux comprendre, nous allons examiner l' Exemple 11. Avant que trois occasions de jeu défensif ne se soient présentées, le batteur frappe un triple et atteint la troisième base. Le batteur suivant bénéficie d'une balle passsée (*passed ball*), ce qui permet au coureur de marquer. Ce point ne doit pas être comptabilisé comme un point mérité du moins pas pour l'instant car, bien que le lanceur soit responsable du fait que le coureur a atteint la troisième base, il n'est pas responsable de sa progression illicite jusqu'au marbre.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur frappe un triple vers le champ droit. */
action { batter -> 3B9 }

/* Le coureur marque un point sur une pass ball. */
action { runner3 -> PB }

Toutefois, il subsiste une possibilité que le point soit comptabilisé comme « mérité » (earned run) si, avant toute occasion de jeu défensif, survient une action dont le lanceur est seul responsable, de telle sorte qu'elle aurait permis au coureur s'il s'était encore trouvé sur la troisième base de marquer.

Pour en revenir à notre exemple, si le frappeur suivant réussit un coup sûr, le point est comptabilisé comme un point mérité, car le coureur aurait pu marquer même sans la pass ball (avance illicite).

Des situations de ce genre, susceptibles de retarder l'attribution d'un point mérité, peuvent résulter d'erreurs permettant aux coureurs de gagner des bases supplémentaires, d'une obstruction à l'encontre des coureurs ou de balles passées (*passed balls*). Il s'agit d'actions irrégulières.

On peut donc affirmer que l'action réglementaire d'un batteur suivant valide l'action du batteur précédent, lorsque ce dernier aurait de toute façon atteint cette base, comme dans le cas que nous venons d'examiner.

Nous allons maintenant clarifier ce qui précède en examinant plusieurs exemples.

Exemple 12: Le premier batteur obtient une base sur balles. Le deuxième batteur frappe un double et force le coureur à avancer jusqu'en troisième base. Le troisième batteur frappe une balle en hauteur en direction du champ centre, ce qui permet au coureur situé en troisième base de marquer. Il s'agit d'un point mérité.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur atteint la première base sur un base sur balles. */
action { batter -> BB }

/* Le frappeur suivant frappe un double vers le champ droit ; le coureur avance de deux bases.*/
action { batter -> 2B8 , runner1 -> ++ }

/* Le batteur suivant frappe un sacrifice fly vers le champ centre, et le coureur en troisième base marque un point. */
action { batter -> SF8 , runner3 -> + earned }

Exemple 13: Le premier frappeur réussit un coup sûr en direction de la troisième base, tandis que le frappeur suivant le fait avancer jusqu'en troisième base grâce à un simple vers le champ droit. Lors d'une tentative de vol du coureur en deuxième base, le receveur effectue un lancer vers le joueur de deuxième base mais ne parvient pas à réaliser le retrait. Le coureur posté en troisième base profite de l'occasion pour avancer jusqu'au marbre et marquer un point. Les deux coureurs se voient créditer d'une base volée et le point est comptabilisé comme un point mérité.

Exemple 14: Avec moins de deux retraits, le premier frappeur obtient une base sur balles.

Le coureur atteint toutefois la base avant la balle et marque un point. Le choix défensif ne constitue pas une occasion de jeu défensif.

Le point est un point mérité.

Exemple 16: Le premier frappeur atteint la première base sur une erreur de lancer du défenseur de troisième base.

Exemple 17: Le premier frappeur atteint la première base grâce à un coup sûr vers le champ gauche et progresse jusqu'en deuxième base grâce au frappeur suivant, qui obtient unz base sur balles.

Alors que le quatrième batteur se présente au marbre, le lanceur commet un *balk* (lancer illégal), ce qui permet aux deux coureurs d'avancer d'une base et entraîne la marque d'un point.
Le batteur se voit alors accorder une base sur balles.
Le batteur suivant reçoit un lancer fou qui permet aux deux coureurs d'avancer d'une base, et un point supplémentaire est marqué.

Exemple 18: Le premier batteur frappe une balle en hauteur dans la zone des fausses balles ; le receveur devrait pouvoir la capter, mais il la laisse tomber. Le marqueur juge qu'il s'agissait d'une prise facile et crédite le receveur d'une erreur. Le batteur reprend sa place et frappe un home run vers le champ centre. Le batteur suivant est retiré sur des prises, et le troisième frappe un triple vers le champ droit.
À ce stade, alors que le quatrième batteur est à la plaque, le lanceur effectue un mauvais lancer, permettant au coureur en troisième base de marquer le deuxième point. Le batteur est ensuite retiré sur des prises.
Le cinquième frappeur réussit un triple vers le champ centre et inscrit ensuite le troisième point grâce à un mouvement illégal du lanceur.
Le premier point marqué sur le home run ne peut être comptabilisé comme point mérité, car la présence du batteur sur base avait été prolongée par une erreur.
Le deuxième point a été mérité, car il a été obtenu en ne concédant que deux occasions de jeu défensif.
Le troisième point, en revanche, n'a pas été comptabilisé comme un point mérité, puisqu'il a été inscrit après la troisième occasion défensive.

Exemple 19: Le premier frappeur obtient un base sur balles.
Le batteur suivant frappe la balle en direction de l'arrêt-court ; celui-ci effectue un lancer vers la deuxième base à temps pour éliminer le coureur, mais il rate la réception du lancer.
Alors que les première et deuxième bases sont occupées, le receveur laisse passer un lancer qu'il aurait dû capter, permettant ainsi aux deux coureurs d'avancer.
Le troisième frappeur frappe une balle en hauteur vers le champ centre, permettant au coureur parti de la troisième base de marquer.
Le quatrième frappeur frappe un simple vers le champ centre, envoyant ainsi le coureur parti de la deuxième base au marbre.
Le cinquième batteur est éliminé sur des prises, et le sixième frappe un home run vers le champ droit, permettant de marquer deux points supplémentaires.
Aucun de ces quatre points n'est mérité.
Le premier point ne peut pas être comptabilisé, car le coureur a atteint la deuxième base sur une erreur.
Le deuxième point a été obtenu avec seulement deux occasions de jeu défensif, mais il faut noter que le coureur a atteint la deuxième base sur une balle échappée ; sans cela, le coup sûr du quatrième batteur ne lui aurait permis d'atteindre au mieux la troisième base, ce qui aurait constitué la troisième occasion de jeu défensif. Les deux autres points ont été marqués après trois occasions de jeu défensif.

Exemple 20: Le premier frappeur frappe un triple vers le champ centre.
Le deuxième frappeur atteint la première base en toute sécurité lorsque l'arrêt-court manque une fly.
Pendant que le troisième frappeur est à la batte, le coureur en première base vole la deuxième base, et l'autre coureur profite du fait que les joueurs de champ se concentrent sur son coéquipier pour marquer un point.
Les troisième et quatrième frappeurs sont retirés sur des prises.
Le cinquième batteur est retiré en première base sur une assistance de l'arrêt-court.

Dans le cas d'une interférence du receveur sur le batteur-coureur (avant que celui-ci n'atteigne la première base), il s'agit d'une erreur déterminante qui, selon le règlement [commentaire de la règle OBR 9.16(a)], n'est pas considérée comme une occasion de jeu défensif ; par conséquent, les points marqués par ce batteur-coureur ne peuvent être comptabilisés comme des points mérités.

Exemple 22: Les deux premiers batteurs sont éliminés sur des prises.
Le troisième frappeur atteint la première base grâce à un coup sûr en direction de la troisième base.
Le quatrième frappeur atteint la première base grâce à un coup sûr vers le champ gauche, permettant au coureur d'avancer jusqu'en deuxième base.

Le sixième frappeur avance en première base après avoir été atteint par un lancer, tous les coureurs avancent et le troisième frappeur de l'ordre au bâton marque un point.
Ce point est comptabilisé comme un point produit, mais non comme un point mérité, car le scoreur officiel ne doit pas présumer que le batteur ayant atteint la première base à la suite d'une interférence du receveur aurait été retiré. Comme ce batteur n'a pas eu la possibilité de compléter son tour de batte, il est impossible de savoir ce qui ce serait passé pour lui sans l'interférence du receveur [OBR 9.16(a) Commentaire].
