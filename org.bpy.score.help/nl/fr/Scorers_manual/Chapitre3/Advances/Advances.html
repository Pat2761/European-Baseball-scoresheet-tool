Avances.

Jusqu'à présent, nous avons examiné les retraits, les erreurs et les coups sûrs. Toutes ces actions de jeu peuvent avoir pour conséquence directe de permettre à un ou plusieurs coureurs déjà sur les bases d'avancer.

Ces avancées peuvent être qualifiées de légales ou d'illégales. Une avancée est illégale lorsqu'elle résulte d'une erreur de base supplémentaire, d'une obstruction ou d'une balle passée. De même, lorsqu'il y a deux retraits et qu'une erreur décisive est commise contre le coureur-frappeur, l'avancée de ce dernier est illégale. Dans tous les autres cas, on parle d'avancées légales.
