Bases volées.

Le scoreur officiel doit créditer une base volée au coureur à chaque fois qu’il gagne une base sans l’intervention d’un coup sûr, d’un retrait, d’une erreur, d’un retrait forcé, d’un choix défensif, d’une balle passée, d’un lancer fou ou d’un balk [OBR 9.07].

L'abréviation pour vol de base est « SB » suivie du numéro du joueur au bâton au moment du vol. Le vol de base a lieu lorsque le lanceur est encore en train d'armer son lancer et que le coureur atteint la base suivante avant ou pendant le lancer.

Lorsqu'un coureur frappe une balle en territoire des bonnes balles lors d'une tentative de vol de base, que la frappe soit sûre ou non, ou si d'autres événements surviennent, l'avancement du coureur est considéré comme ayant été effectué grâce à la frappe, et non comme un vol de base. Il en va de même pour les coureurs forcés, lorsqu'un frappeur obtient la première base suite à un but sur balles, un frappeur atteint, une interférence ou une obstruction.

Une tentative de vol de base doit être effectuée dans l'intervalle de temps qui commence lorsque le lanceur est sur le monticule et se termine lorsque la balle est morte ou qu'elle est de nouveau en possession du lanceur sur son monticule.

Exemple 83: Si, avec des coureurs en première et troisième base, le receveur lance en première base pour tenter d'éliminer le coureur hors base, et que le coureur en troisième base en profite pour atteindre le marbre, ce dernier coureur doit se voir créditer d'un vol de base.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un triple au champ centre. */
action { batter -> 3B8 }

/* Le frappeur suivant atteint la première base sur un « base on ball ». */
action { batter -> BB }

/* Le coureur en troisième base vole le marbre */
action { runner3 -> SB }

Une base volée doit également être attribuée dans les cas suivants:

  1. Lorsqu’un coureur commence sa course vers la base suivante avant que le lanceur ne délivre la balle et que ce lancer ne soit inscrit comme lancer fou ou une balle passée [OBR 9.07(a)].

    Exemple 84: Si le coureur parvient à avancer d'une seule base, on lui attribue un vol de base. S'il parvient à avancer d'une base supplémentaire, on lui attribue un vol de base pour la première base et un lancer fou ou une balle passée pour la base supplémentaire.

    WBSC Transcription dans l'outil de scorage Outil
    /* Le premier frappeur remporte la première base sur un 'base on ball' */
    action { batter -> BB }

    /* Il vole la deuxième base et profite d'un lancer fou pour atteindre la troisième base. */
    action { runner1 -> SB WP }
  2. Quand un coureur essaye de voler une base, et que le receveur, après avoir reçu le lancer, fait un mauvais relais en essayant d’empêcher le vol de base [OBR 9.07(b)].

    Exemple 85: Dans ce cas, le vol de base est crédité au coureur et aucune erreur n'est imputée au receveur.

    WBSC Transcription dans l'outil de scorage Outil
    /* Le premier frappeur gagne la première base sur un 'base on ball' */
    action { batter -> BB }

    /* Il vole la deuxième base */
    action { runner1 -> SB }

    Exemple 86: … à moins que le coureur n’ait réussi à avancer d’une base supplémentaire, auquel cas le receveur devrait être accusé d’une erreur de base supplémentaire.

    WBSC Transcription dans l'outil de scorage Outil
    /* Le premier frappeur gagne la première base sur un 'base on ball' */
    action { batter -> BB }

    /* Il vole la deuxième base et profite d'une erreur pour atteindre la troisième base. */
    action { runner1 -> SB e2T }
  3. Lorsqu’un coureur, qui essaie de voler une base, ou après avoir été surpris en dehors de celle-ci, échappe au retrait en courant entre les bases et gagne la suivante sans l’aide d’une erreur [OBR 9.07(c)].
  4. Si un autre coureur avance aussi sur ce jeu, le scoreur officiel doit créditer les deux coureurs d’une base volée [OBR 9.07(c)].

    Exemple 87: Tous ces coureurs devraient être crédités de bases volées.

    WBSC Transcription dans l'outil de scorage Outil
    /* Le premier frappeur réussit un simple au champ gauche. */
    action { batter -> 1B7 }

    /* Le frappeur suivant gagne la première base sur un « Hit by pitch », le coureur avance */
    action { batter -> HP , runner1 -> + }

    /* Les deux coureurs volent une base */
    action { runner1 -> SB , runner2 -> SB }

    Exemple 88: …à moins que l’un d’eux ne soit éliminé (ou n’aurait été éliminé sans une erreur de champ), auquel cas les autres coureurs se voient attribuer un choix défensif.
    Dans ce cas, placez une flèche entre les deux annotations pour indiquer que le vol de base et le choix du joueur de champ se sont produits lors d'une même action.

    WBSC Transcription dans l'outil de scorage Outil
    /* Le premier frappeur réussit un simple au champ gauche. */
    action { batter -> 1B7 }

    /* Le frappeur suivant gagne la première base sur un « Hit by pitch », le coureur avance */
    action { batter -> HP , runner1 -> + }

    /* Les deux coureurs volent une base, mais celui qui est en tête est éliminé. */
    action { runner1 -> O/2 , runner2 -> CS25 }
  5. Si un coureur avance lorsqu'un autre coureur, tentant de voler et, pris en souricière, échappe au retrait en courant entre les bases et retourne sauf, sans l’aide d’une erreur, à la base qu’il occupait à l’origine [OBR 9.07(c)].

    Dans ce cas, le coureur est crédité d'un vol de base. Si l'autre coureur est éliminé, en revanche, le coureur qui a avancé est crédité d'un choix du défenseur (O/.).

    Chaque base volée est créditée au coureur qui l'a volée, et cela se fait en traçant un trait vertical dans la colonne appropriée des statistiques offensive de la feuille de scorage, à côté du nom du joueur. La même notation est utilisée dans le tableau du receveur (bases volées concédées), à condition que le défenseur au marbre ait eu la possibilité de s'opposer à l'action, ou que, au moment de la tentative de vol, un lancer légal ait été effectué.
    Si un vol de base est accordé suite à un retrait au champ, il doit être attribué au lanceur. Inscrivez le nom du lanceur dans la case du receveur, sur une ligne de couleur, et tracez un trait vertical derrière ce nom. Ainsi, le total des vols de base sera identique à celui indiqué dans les statistiques offensives.

Les bases volées ne doivent pas être créditées dans les cas suivants:

  1. Lorsqu’un coureur est retiré pour avoir été touché après avoir glissé au-delà d’une base, alors qu’il tentait de retourner à cette base ou de gagner la base suivante [OBR9.07(e)].

    Le coureur est retiré pour “caught stealing”.

    ATTENTION: Si le coureur dépasse la base qu'il tentait de voler et qu'il est touché, il est accusé d'avoir volé la base et est déclaré éliminé.
  2. Lorsque d’après le jugement du scoreur officiel, un coureur qui essaie de voler est sauf à la suite d’un relais mal attrapé [OBR 9.07(f)].

    Exemple 89: Dans ce cas, le coureur est retiré pour « caught stealing », une erreur est imputée au défenseur qui a raté le lancer et une assistance ainsi que le vol de base sont crédités au défenseur qui a effectué le lancer.

    WBSC Transcription dans l'outil de scorage Outil
    /* Le premier frappeur réussit un simple contre l'arrêt-court. */
    action { batter -> 1B6 }

    /* Le coureur tente un vol de base en deuxième base, et il aurait été éliminé si le défenseur de la deuxième base n'avait pas commis d'erreur. */
    action { runner1 -> CS2E4 }
  3. Le scoreur officiel ne doit pas inscrire de base volée lorsqu’un coureur avance en raison de l’indifférence de l’équipe en défense [OBR 9.07(g)].

    Exemple 90: Bien qu'ayant constaté que le coureur en première base tente de voler une base, le receveur ne fait rien pour l'en empêcher. Le marqueur officiel juge qu'il n'y a aucun motif stratégique légitime pour ne pas effectuer le lancer ; il s'agit donc d'une indifférence défensive (vol de base non défendu). Le coureur avance en deuxième base et l'action est donc enregistrée avec « O/2 ». Ceci est également expliqué dans le commentaire de l'OBR [9.07(g)].

    WBSC Transcription dans l'outil de scorage Outil
    /* Le premier frappeur envoie une balle en hauteur au champ centre, le défenseur commet une erreur en tentant de l'attraper. */
    action { batter -> E8F }

    /* Le frappeur suivant frappe un coup sûr au champ droit, le coureur avance de deux bases */
    action { batter -> 1B9 , runner1 -> ++ }

    /* Le coureur en première base tente de voler la base, la défense reste indifférente. */
    action { runner1 -> O/2 }

    Si le receveur ne tente pas d'éliminer le coureur qui tente de voler une base, mais tente plutôt une autre action, comme lancer la balle au lanceur ou en deuxième base qui s'est avancé, ou en troisième base dans le but d'éliminer le coureur en troisième base ou de le faire avancer, une base volée est crédité au coureur qui a avancé.

    À moins que la tentative de faire avancer le coureur en troisième base ne réussisse et qu'il soit éliminé, auquel cas un vol de base raté est crédité au coureur en troisième base et un choix du défenseur au coureur qui a atteint la deuxième base.

    NOTE: Si le coureur n'a pas tenté d'avancer mais a été éliminé en retournant en troisième base, il n'est pas accusé d'avoir été « pris en flagrant délit de vol de base ».

    ATTENTION: Lorsqu'une souricière échoue sans erreur et que le coureur retourne à sa base, rien n'est inscrit sur la feuille de match. En revanche, si le coureur retourne à sa base suite à une erreur, l'assistance, l'erreur et la tentative de vol de base doivent être notées.

    Il convient à ce stade de conclure la section sur les bases volées par quelques exemples précis.

    Exemple 91: Avec les première et troisième bases occupées, le coureur en première base tente de voler la deuxième. Le receveur lance la balle en deuxième base pour l'éliminer. Le coureur en troisième base, voyant cela, se lance à la conquête du marbre. Si le coureur qui a tenté de voler la deuxième base atteint également la base sain et sauf, les deux coureurs se voient attribuer un vol de base.

    WBSC Transcription dans l'outil de scorage Outil
    /* Le premier frappeur gagne la première base sur un 'base on ball' */
    action { batter -> BB }

    /* Le frappeur suivant frappe un coup sûr au champ droit, le coureur avance de deux bases */
    action { batter -> 1B9 , runner1 -> ++ }

    /* Les deux coureurs volent une base */
    action { runner1 -> SB , runner3 -> SB }

    Exemple 92: En revanche, si le coureur qui tente de voler la deuxième base est éliminé (ou l'aurait été sans une erreur), il est accusé d'avoir été « pris en flagrant délit de vol », et le point de l'autre coureur est comptabilisé comme un choix du joueur de champ.

    WBSC Transcription dans l'outil de scorage Outil
    /* Le premier frappeur gagne la première base sur un 'base on ball' */
    action { batter -> BB }

    /* Le frappeur suivant frappe un coup sûr au champ gauche, le coureur avance de deux bases */
    action { batter -> 1B7 , runner1 -> ++ }

    /* Les deux coureurs ont volé une base, le coureur en première base aurait dû être éliminé. */
    action { runner1 -> CS2E4 , runner3 -> O/2 }

    Exemple 93: Avec des coureurs en première et deuxième base, le coureur en deuxième base tente de voler la troisième. Le lancer est incontrôlé et, par conséquent, le coureur en première base atteint la deuxième. Dans ce cas, un vol de base est accordé au coureur qui a atteint la troisième base, et une avancée due à un lancer incontrôlé est accordée à l'autre coureur, qui n'aurait pas pu atteindre la deuxième base sans ce lancer.

    WBSC Transcription dans l'outil de scorage Outil
    /* Le premier frappeur gagne la première base sur un 'base on ball' */
    action { batter -> BB }

    /* Le frappeur suivant atteint la base sur un « base on ball », le coureur gagne une base */
    action { batter -> BB , runner1 -> + }

    /* Le coureur en deuxième base vole une base, le coureur en première base avance en deuxième sur un lancer fou */
    action { runner1 -> WP , runner2 -> SB }

    Exemple 94: Avec des coureurs en première et troisième base, le coureur en première tente de voler la deuxième. Le receveur rate son relais vers la deuxième base et le coureur en troisième en profite pour marquer un point. Le vol de base est validé pour le coureur en première base, et l'avance du coureur en troisième est attribuée à une erreur du receveur.

    WBSC Transcription dans l'outil de scorage Outil
    /* Le premier frappeur réussit un triple au champ droit. */
    action { batter -> 3B9 }

    /* Le deuxième frappeur atteint la première base en raison d'une interférence du receveur. */
    action { batter -> INT }

    /* Le coureur vole la deuxième base, le receveur tente d'empêcher le vol mais commet une erreur, et le coureur en troisième base en profite pour marquer un point. */
    action { runner1 -> SB , runner3 -> e2T }

    Exemple 95: Le coureur en troisième base est pris au piège entre la troisième base et le marbre, mais parvient à atteindre le marbre sain et sauf sans qu'aucune erreur ne soit commise par la défense. Il est crédité d'un vol de base.

    WBSC Transcription dans l'outil de scorage Outil
    /* Le premier frappeur atteint la troisième base sur un triple au champ droit */
    action { batter -> 3BRC }

    /* Malgré la souricière, le coureur marque le point */
    action { runner3 -> SB }

    Exemple 96: Avec des coureurs en première et deuxième base, il y a double vol de base. Le receveur, au lieu de défendre le coureur en deuxième base, défend celui en première, et lorsqu'il élimine le coureur précédent, ce dernier marque. L'avancée jusqu'au marbre constitue également un vol de base, et le trait de liaison indique la continuité de l'action.

    WBSC Transcription dans l'outil de scorage Outil
    /* Le premier frappeur gagne la première base sur un 'base on ball' */
    action { batter -> BB }

    /* Le frappeur suivant gagne la première base sur un « base on ball », le coureur gagne une base */
    action { batter -> BB , runner1 -> + }

    /* Les coureurs volent une base, et le coureur arrivant en troisième base en profite pour voler le marbre. */
    action { runner1 -> SB , runner2 -> SB SB }
