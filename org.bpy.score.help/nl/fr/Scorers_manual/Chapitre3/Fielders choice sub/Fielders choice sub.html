Choix défensif.

L’abréviation « FC » est également utilisée dans la case de première base pour indiquer que l’avancement du frappeur-coureur en première base est dû à un choix du défenseur. Contrairement à la notation « balle occupée », qui est toujours précédée d’une ou plusieurs occasions de jeu en défense, « FC » est utilisé lorsque le jeu alternatif, bien qu'exécuté correctement par la défense, ne permet pas d'éliminer un adversaire.

Par conséquent, le choix du défenseur ne doit pas être considéré comme une opportunité défensive.

La notation à utiliser est « FC » suivi de deux nombres, le premier représentant le défenseur qui a initié le jeu et le second identifiant la base vers laquelle il a lancé.

Exemple 71: La balle au sol à l'intérieur du terrain est récupérée par le défenseur de la troisième base qui choisit de tenter de retirer le coureur forcé et ne parvient pas à effectuer l'élimination.
Cela indique également que lorsqu'une balle au sol à l'intérieur du terrain est récupérée par le défenseur de la deuxième base, qui choisit de jouer pour le coureur forcé arrivant de la première base et lance au joueur d'arrêt-court, mais ne parvient pas à effectuer l'élimination, nous marquons FC44 pour le frappeur (le premier 4 est le défenseur qui a initié le jeu et le second 4 est la base vers laquelle il a lancé).

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un simple contre le lanceur. */
action { batter -> 1B1 }

/* Le frappeur suivant envoie la balle en direction du défenseur de la troisième base, qui choisit de la relayer en deuxième base, mais sans succès. */
action { batter -> FC54 , runner1 -> + }

La mention « FC » dans le carré de première base indique qu’une tentative de jeu pour cette base aurait entraîné l’élimination du frappeur-coureur, comme illustré dans l' Exemple 72:

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un simple contre le lanceur */
action { batter -> 1B1 }

/* Le frappeur suivant envoie la balle vers le défenseur de la troisième base, qui la relaie en première base pour éliminer le coureur. */
action { batter -> 54 , runner1 -> + }

Exemple 73: Si le scoreur n'est pas convaincu que le frappeur aurait été éliminé en première base, le résultat sera un coup sûr.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un simple contre le lanceur */
action { batter -> 1B1 }

/* Le frappeur suivant envoie la balle en direction de la troisième base, qui choisit de la relayer en deuxième base, mais sans succès. */
action { batter -> 1B5 , runner1 -> + }

Exemple 74: Avec les première et deuxième bases occupées, sur un amorti du neuvième frappeur, le lanceur tente sans succès d'éliminer le coureur forcé en troisième base, donnant ainsi au frappeur-coureur l'opportunité d'atteindre la première base.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur obtient la première base sur un « base on ball ». */
action { batter -> BB }

/* Le frappeur suivant réussit un coup sûr vers la deuxième base, le coureur avance jusqu'en deuxième base. */
action { batter -> 1B4 , runner1 -> + }

/* Le frappeur réussit un amorti sacrifice, mais le défenseur choisit d'éliminer le coureur en deuxième base sans succès.*/
action { batter -> SHFC15 , runner1 -> + , runner2 -> + }

Exemple 75: Si, dans l’action décrite ci-dessus, le coureur de tête avait été éliminé (ou avait atteint la base en toute sécurité suite à une erreur de l’un des deux défenseur qui ont participé à l’action), l’arrivée du frappeur-coureur en première base aurait été enregistrée comme une « balle occupée ».

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur obtient la première base sur un « base on ball ». */
action { batter -> BB }

/* Le frappeur suivant réussit un coup sûr vers la deuxième base, le coureur avance jusqu'en deuxième base. */
action { batter -> 1B4 , runner1 -> + }

/* Le frappeur suivant tente un amorti, le lanceur récupère la balle et choisit d'éliminer le coureur arrivant en troisième base sur trois prises. */
action { batter -> O1b , runner1 -> O1 , runner2 -> 15 }

L' exemple 76: montre ce qui se passe lorsqu'il n'y a aucune possibilité de retier un des coureurs.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur obtient la première base sur un « base on ball » */
action { batter -> BB }

/* Le frappeur suivant réussit un coup sûr vers la deuxième base, le coureur avance jusqu'en deuxième base */
action { batter -> 1B4 , runner1 -> + }

/* Le frappeur suivant tente un amorti vers le lanceur, qui récupère la balle et la renvoie pour éliminer le coureur qui se dirige vers la troisième base, mais sans succès. */
action { batter -> 1B1b , runner1 -> + , runner2 -> + }

ATTENTION: Lorsque, dans une telle action, le scoreur juge que la défense n'aurait pas été en mesure d'effectuer d'autres éliminations, y compris celle du frappeur-coureur, ce dernier doit se voir attribuer un coup sûr.

Exemple 77: Le septième frappeur tente sa chance sur la troisième prise, manquée par le receveur. Malgré la récupération de la balle à temps pour éliminer le coureur en première base, le receveur essaie d'éliminer le coureur qui a quitté sa base sur la balle passée. Le coureur atteint le but sain et sauf.
L’avancement en troisième base se produit sur une balle passée, tandis que l’avancement du frappeur-coureur en première base est enregistré comme « FC », précédé de la prise et du nombre cumulatif de retraits sur prises, et suivi du numéro du receveur qui a effectué le lancer et du numéro de la base vers laquelle le jeu alternatif a été effectué.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un double au champ centre. */
action { batter -> 2B8 }

/* Troisième prise sur une balle passée, le receveur choisit d'éliminer le coureur arrivant en troisième base, mais sans succès. */
action { batter -> KSFC25 , runner2 -> PB }

L’avancement en troisième base se produit sur une balle passée, tandis que l’avancement du frappeur-coureur en première base est enregistré comme « FC », précédé de la prise et du nombre cumulatif de retraits sur prises, et suivi du numéro du receveur qui a effectué le lancer et du numéro de la base vers laquelle le jeu alternatif a été effectué.

l' exemple 78: Illustre les effets d'une action réussie pour atteindre la première base. Aucune balle passée n'est imputée au receveur, en raison de l'élimination.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un double au champ centre. */
action { batter -> 2B8 }

/* Troisième prise sur une balle passée, le receveur élimine le frappeur-coureur avec un lancer en première base */
action { batter -> KS23 , runner2 -> O/2 }
