Un lancer légal touche un coureur qui tente de marquer.

Le jeu est arrêté (la balle est morte) et les coureurs avancent d’une base ou retournent à leurs bases sans pouvoir être retirés quand … Tout lancer régulier qui touche un coureur en train d’essayer de marquer ; les coureurs avancent [OBR 5.06(c)(8)].

Règlge 6.05(n), Cette règle, qui sera examinée plus en détail ultérieurement, décrit les conséquences pour un coureur tentant de voler le marbre d'être touché par une balle lancée dans la zone de strike. Il est important de noter que le lancer légal visé par cette règle doit toucher le coureur avant d'entrer dans la zone de strike.

Dans cette situation, le frappeur se voit attribuer une balle, le point est marqué et le coureur touché se voit attribuer un vol de base.

En ce qui concerne les avancées des autres coureurs, il faut évaluer si, au moment du lancer, l'équipe offensive était engagée dans une tentative de vol de base ; si oui, le vol doit leur être crédité ; sinon, leurs avancées sont notées dans la case des bases qui leur ont été attribuées avec le symbole « WP » ou « PB ».

Il convient de noter que lorsque la balle en question est la quatrième, le frappeur se voit attribuer la première base et toutes les avances forcées des coureurs sont traitées comme si elles avaient eu lieu sur un Base on ball, y compris un point marqué avec les bases pleines.

Exemple 111: Au cours d'une tentative de double vol de base, le coureur de tête est touché par la balle lancée avant d'atteindre le marbre.
Comme il était manifestement en train de voler une base, les deux avancées sont enregistrées avec l'abréviation « SB ».

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur gagne la première base sur un 'hit by pitch' */
action { batter -> HP }

/* Le coureur en première base avance suite à un balk. */
action { runner1 -> BK }

/* Le frappeur suivant frappe un simple vers l'arrêt-court, le coureur avance d'une base */
action { batter -> 1B6 , runner2 -> + }

/* Les deux coureurs volent une base */
action { runner1 -> SB , runner3 -> SB }

Exemple 112: Avec des coureurs en première et troisième base, le coureur de tête est touché par la balle lancée légalement avant d'atteindre le marbre.
Le point est légal, le coureur en tête se voit créditer d'un vol de base et l'avancement de l'autre coureur en deuxième base est enregistré avec la notation « WP » ou « PB », selon la situation.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur gagne la première base sur un 'hit by pitch' */
action { batter -> HP }

/* Le coureur en première base avance suite à un balk. */
action { runner1 -> BK }

/* Le frappeur suivant frappe un simple au champ droit, le coureur avance d'une base */
action { batter -> 1B9 , runner2 -> + }

/* Le premier coureur vole une base, tandis que le second profite d'un wild pitch. */
action { runner1 -> WP , runner3 -> SB }

Exemple 113: Avec les première et troisième bases occupées, et un compte complet pour le frappeur, il y a une tentative de double vol.
Le coureur de tête est touché par la balle avant d'atteindre la zone de strike.
Le point est accordé, le coureur qui a marqué est crédité d'un vol de base et le frappeur, comme il s'agissait de la quatrième balle, se voit attribuer la première base.
Ce dernier événement justifie également l’avancée du deuxième coureur, qu’il ait déjà tenté ou non de voler une base (avancée forcée).

WBSC Transcription dans l'outil de scorage Outil
/* Le premier batteur frappe une balle en direction de l'arrêt-court, qui commet une erreur. */
action { batter -> E6 }

/* Le frappeur suivant frappe un simple au champ droit, le coureur avance de deux bases */
action { batter -> 1B9 , runner1 -> ++ }

/* Le frappeur suivant obtient un base on ball pendant que le coureur volait une base. */
action { batter -> BB , runner1 -> + , runner3 -> SB }

Exemple 114: Avec les bases pleines, deux retraits et un compte complet pour le frappeur, la balle lancée légalement glisse de la main du lanceur et frappe le coureur qui quitte la troisième base avant d'entrer dans la zone de strike.
Étant donné que le lancer est également la quatrième balle, toutes les avancées (forcées) se produisent en conséquence de la base accordée au quatrième frappeur, indépendamment de toute tentative de vol de base.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un coup sûr au champ gauche. */
action { batter -> 1B7 }

/* Le frappeur suivant envoie une balle en hauteur au champ centre, mal attrapée, et le coureur avance grâce à cette erreur. */
action { batter -> E8F , runner1 -> (2) }

/* Le coureur suivant atteint la première base sur un « Hit by pitch », les deux coureurs avancent. */
action { batter -> HP , runner1 -> + , runner2 -> + }

/* Le frappeur suivant gagne la première base sur un 'base on ball'. */
action { batter -> BB , runner1 -> + , runner2 -> + , runner3 -> + }
