Retrait sur tentative de vol.

Le scoreur officiel doit attribuer à un coureur un "retrait sur tentative de vol" s'il est retiré, ou aurait été retiré s’il n’y avait pas eu erreur, alors que ce coureur : [OBR 9.07(h)]:

  1. essaie de voler une base,
  2. est surpris en dehors de sa base par un retour rapide de la balle sur celle-ci (pickoff) et tente d’avancer (tout mouvement vers la base suivante doit être considéré comme une tentative d’avancer), ou
  3. glisse au-delà d’une base qu’il est en train de voler.

Commentaire: Dans le cas où la balle lancée passe loin du receveur et que le coureur est retiré en tentant d'avancer, aucun retrait sur tentative de vol ne doit être attribué. Le scoreur officiel ne doit pas attribuer de retrait sur tentative de vol lorsqu’un coureur avance du fait d'une obstruction ou lorsque le coureur est retiré en raison de l'interférence du batteur

Il n’attribuera pas de retrait sur tentative de vol au coureur s’il n’avait pas crédité de vol de base au cas où le coureur aurait été sauf (par exemple, lorsque le receveur retire le coureur sur un relais alors que le coureur essayait d'avancer après qu'un lancer soit passé loin du receveur.

La notation pour « vol de base raté » est « CS » suivie des numéros des joueurs ayant effectué l'assistance et l'élimination. L'assistance est très souvent, mais pas systématiquement, réalisée par le receveur, comme le montrent les exemples suivants. À l'abréviation CS, on ajoute dans un coin le numéro de l'ordre de passage au bâton du joueur qui était au bâton au moment du vol de base raté.

Exemple 97: Le coureur en première base est pris en flagrant délit de vol grâce à l'aide du receveur en deuxième base, alors que le troisième joueur de l'ordre de frappe est au bâton.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un coup sûr contre l'arrêt-court. */
action { batter -> 1B6 }

/* Le coureur tente de voler la deuxième base, mais il est éliminé. */
action { runner1 -> CS24 }

Exemple 98: Le coureur en première base est éliminé par un lancer précis du lanceur. Il tente alors d'avancer, mais est retiré par le défenseur de la deuxième base grâce à une assistance du défenseur de la première base. Les assistances sont comptabilisées pour le lanceur et le défenseur de la première base, et l'élimination pour le défenseur de la deuxième base. Dans ce cas, le receveur n'est pas crédité d'une tentative de vol de base, mais le lanceur. Inscrivez le nom du lanceur dans la case du receveur, dans la ligne de couleur correspondante, et tracez un trait vertical derrière ce nom. Ainsi, le total des bases volés sera identique à celui indiqué dans les statistiques offensives.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un coup sûr contre l'arrêt-court. */
action { batter -> 1B6 }

/* Le coureur tente de voler la deuxième base, mais il est éliminé. */
action { runner1 -> CS134 }

Exemple 99: Lorsqu'un coureur en première base est éliminé par un lancer précis du lanceur, tente d'avancer puis retourne en première base où il est retiré par le défenseur de la première base, on note l'action complète. Dans cet exemple, les assistances sont créditées au lanceur, au joueur de première base et à l'arrêt-court, et l'élimination est créditée au joueur de première base. Dans ce cas, le retrait au vol de base n'est pas crédité au receveur, mais au lanceur.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un coup sûr contre l'arrêt-court. */
action { batter -> 1B6 }

/* Le coureur tente de voler la deuxième base, mais il est éliminé. */
action { runner1 -> CS1363 }

Exemple 100: Lorsqu'un coureur retourne en toute sécurité en première base suite à une erreur de réception du défenseur de la première base, il faut consigner l'erreur car elle prolonge la présence du coureur sur les bases [OBR 9.12]. Une assistance est attribuée au lanceur, au défenseur de la première base et à l'arrêt-court, et une erreur est également imputée au défenseur de la première base. Le vol de base est attribué au lanceur.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un coup sûr contre l'arrêt-court. */
action { batter -> 1B6 }

/* Le deuxième frappeur réussit un coup sûr en deuxième base, le coureur avance. */
action { batter -> 1B4 , runner1 -> + }

/* Le coureur tente de voler une base. Il est piégé mais parvient à retourner sur sa base grâce à une erreur. */
action { noAdvance on runner1 -> CS136E4 }

Exemple 101: ATTENTION: Si un coureur tente de voler le marbre et est éliminé par le receveur en attrapant un lancer régulier du lanceur, le lanceur ne se voit pas créditer d'une assistance.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un triple au champ centre. */
action { batter -> 3B8 }

/* Le coureur tente de voler le marbre mais est éliminé par le receveur. */
action { runner3 -> CS2 }

Exemple 102: Le lanceur, comprenant à temps l'intention du coureur, descend du marbre et lance la balle au receveur. Il obtient une assistance.
Le scoreur doit donc être très attentif au comportement du lanceur lorsqu'un coureur tente de voler le marbre.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un triple au champ centre. */
action { batter -> 3B8 }

/* Le coureur tente de voler le marbre mais est éliminé par le receveur. */
action { runner3 -> CS12 }

Exemple 103: Avec des coureurs en première et deuxième base, il y a un double vol de base. Le receveur tente d'éliminer le coureur en troisième base, mais le joueur de troisième base rate le relais, et le coureur est sauf en troisième base. On attribue une assistance au receveur et une erreur au défenseur de la troisième base sur la tentative de vol de base réussie pour le coureur de la deuxième à la troisième base, et un choix défensif au coureur de la première à la deuxième base.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un coup sûr au champ gauche. */
action { batter -> 1B7 }

/* Le deuxième frappeur atteint la première base sur « hit by pitch », le coureur avance. */
action { batter -> HP , runner1 -> + }

/* Les deux coureurs volent une base, mais l'un d'eux aurait dû être éliminé. */
action { runner1 -> O/2 , runner2 -> CS2E5 }

Exemple 104: Avec des coureurs en première et deuxième base, le coureur en deuxième base tente de voler la troisième base. Le receveur effectue un bon lancer, mais le défenseur de la troisième base fait une erreur. Voyant l'erreur du défenseur de la troisième base, le coureur de première base décide d'avancer en deuxième base (donc pas en même temps que celui de deuxième base). Comptez une assistance pour le receveur et une erreur pour le défenseur de troisième base sur la tentative de vol de base du coureur en troisième base. Inscrivez le numéro du coureur en tête de l'ordre de passage au bâton entre parenthèses dans la case de deuxième base de ce dernier coureur.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un coup sûr au champ gauche. */
action { batter -> 1B7 }

/* Le deuxième frappeur atteint la première but sur un « hit by pitch », le coureur avance. */
action { batter -> HP , runner1 -> + }

/* Les deux coureurs volent une base, mais l'un d'eux aurait dû être éliminé. */
action { runner1 -> (1) , runner2 -> CS2E5 }

Exemple 105: Avec un coureur en première base, le frappeur tente un amorti sacrifice et ne parvient pas à toucher la balle. Le coureur, qui avait déjà commencé sa course vers la deuxième base, tente de revenir mais est éliminé sur une assistance du receveur. Dans ce cas également, la raison de l'élimination pour vol de base doit être consignée dans les notes.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur gagne la première base sur un 'base on ball' */
action { batter -> BB }

/* Le coureur en première base est éliminé en tentant de voler une base */
action { batter -> CS24 }

Exemple 106: Surpris par un pick-off, un coureur en première base tente de voler la deuxième. Alors que la défense a une occasion en or d'éliminer le coureur, le lanceur rate son lancer, la balle étant hors de portée du joueur de première base. Le coureur atteint ainsi la deuxième base sain et sauf.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un coup sûr au champ gauche */
action { batter -> 1B7 }

/* Le coureur vole la deuxième base, il n'est pas éliminé à cause d'une erreur. */
action { runner1 -> CSE1T }

Exemple 107: Si le coureur commence à avancer vers la deuxième base, mais retourne sain et sauf au premier, il faut tout de même signaler l'erreur, car cela prolonge son temps passé sur les bases. Indiquez l'erreur entre la première et la deuxième base.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un coup sûr au champ gauche */
action { batter -> 1B7 }

/* Le coureur vole la deuxième base, il n'est pas éliminé à cause d'une erreur. */
action { noAdvance on runner1 -> CSE1T }
