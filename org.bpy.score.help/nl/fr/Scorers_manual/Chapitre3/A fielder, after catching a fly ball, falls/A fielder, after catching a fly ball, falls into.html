Un joueur de champ, après avoir attrapé une balle en vol, tombe sur un banc ou une tribune, ou dans une foule de spectateurs sur le terrain.

Chaque coureur, autre que le batteur, peut, sans risque d’être retiré, avancer d’une base quand … Un défenseur, après avoir attrapé un fly, marche ou tombe sur toute surface hors des limites de jeu [OBR 5.06(b)(3)(C)].

La règle stipule que dans une telle situation, les coureurs avancent d'une base (la balle est morte). Cette avance légale est notée avec le numéro du frappeur qui a été retiré sur la balle en l'air. Si le scoreur estime que le coureur en troisième base aurait atteint le marbre sans l'incident, le frappeur se voit créditer d'un sacrifice (FSF).

Exemple 119: Sans aucun retrait et avec les bases pleines, le septième frappeur envoie une courte balle en territoire des fausses balles vers l'abri des joueurs de troisième base. Le joueur de champ effectue la prise, mais tombe dans l'abri au moment de l'impact.
L'arbitre désigne le frappeur comme éliminé et tous les coureurs avancent d'une base.
Chaque avancée est notée avec le numéro du batteur.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un coup sûr au champ centre */
action { batter -> 1B8 }

/* Le coureur avance sur un lancer fou */
action { runner1 -> WP }

/* Le frappeur suivant réussit un coup sûr contre le receveur, le coureur avance. */
action { batter -> 1B2 , runner2 -> + }

/* Le frappeur suivant atteint la première base sur un « base on ball », le coureur avance. */
action { batter -> BB , runner1 -> + }

/* Le frappeur suivant envoie une balle en l'air dans la zone des fausses balles, qui est attrapée au vol, et tous les coureurs avancent */
action { batter -> FF5 , runner1 -> + , runner2 -> + , runner3 -> + }

ATTENTION: Lorsque le joueur de champ, après avoir attrapé une balle fausse, se retrouve dans l'abri mais ne tombe pas, le frappeur est déclaré éliminé et la balle reste en jeu.

Exemple 120: Sans retrait et avec un coureur en troisième base, le frappeur envoie une longue balle en territoire des fausses balles vers le champ gauche. Le défenseur du champ gauche, après une course effrénée, parvient à attraper la balle mais tombe contre la clôture, se retrouvant hors du terrain. L'arbitre déclare le frappeur retiré et le coureur marque.
L'avance est indiquée par le numéro du frappeur dans l'ordre de passage au bâton.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un coup sûr au champ centre */
action { batter -> 1B8 }

/* Puis il vole une base */
action { runner1 -> SB }

/* Il profite ensuite d'un lancer fou pour atteindre la troisième base */
action { runner2 -> WP }

/* Le frappeur suivant envoie une balle en hauteur dans la zone des fausses balles, au champ gauche, qui est attrapée, et le coureur marque un point */
action { batter -> FF7 , runner3 -> + }

ATTENTION: Si, de l'avis du scoreur, le coup frappé au champ extérieur aurait permis au coureur de marquer dans tous les cas, il doit le comptabiliser comme un sacrifice fly, et le point est considéré comme ayant été produit.

ATTENTION: Étant donné le nombre et la variété des causes possibles, il est essentiel, en cas d'une de ces avancées particulières, de noter dans l'espace approprié du rapport de score le numéro de la règle qui a donné lieu à l'avancée.
