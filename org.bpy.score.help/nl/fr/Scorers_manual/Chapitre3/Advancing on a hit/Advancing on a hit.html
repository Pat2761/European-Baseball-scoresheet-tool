Avancer sur un coup sur.

Lorsqu'un coureur avance sur un coup sûr, cela est enregistré en inscrivant le numéro de l'ordre de passage au bâton du frappeur qui a obtenu le coup sûr dans la case correspondant à la base atteinte. Ainsi, ( Exemple 26 ) Si les première et deuxième bases sont occupées et que le troisième frappeur dans l'ordre des frappeurs réussit un simple, permettant aux coureurs d'atteindre respectivement la deuxième et la troisième base, l'arrivée des coureurs à la deuxième et à la troisième base est enregistrée par le chiffre trois dans les cases correspondantes.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier batteur frappe un double dans le champ gauche */
action { batter -> 2B7 }

/* Le batteur suivant gagne la première base sur un 'base on ball' */
action { batter -> BB }

/* Le batteur suivant frappe un simple dans le champ centre, les deux coureurs avance */
action { batter -> 1B8 , runner1 -> + , runner2 -> + }

Exemple 27: Avec un coureur en première base, le frappeur (deuxième dans l'ordre de passage au bâton) réussit un simple, permettant au coureur d'atteindre la troisième base. Ceci est noté par le chiffre deux dans la case correspondante.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier batteur gagne la première base sur un 'base on ball' */
action { batter -> BB }

/* Le batteur suivant frappe un hit en champ centre, le coureur gagne deux bases */
action { batter -> 1B8 , runner1 -> ++ }

Exemple 28: Avec un coureur en première base, le frappeur (huitième dans l'ordre des frappeurs) réussit un double, permettant au coureur d'atteindre le marbre. Le chiffre huit est donc inscrit dans la case du marbre.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier batteur gagne la première base sur un 'base on ball' */
action { batter -> BB }

/* Le batteur suivant frappe un double en champ gauche, le coureur gagne trois bases et marque le point */
action { batter -> 2BLC , runner1 -> +++ }
