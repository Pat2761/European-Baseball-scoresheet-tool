Points produits.

Selon la règle 9.04 du règlement OBR, un point est considéré comme produit (RBI) si le coureur qui a marqué a été amené au marbre par le frappeur (ou a marqué grâce au frappeur). Il s'ensuit qu'un point est comptabilisé comme produit si le coureur a atteint le marbre grâce à :

  • un coup sûr;
  • une balle frappée qui a entraîné l'élimination du frappeur ou d'un autre coureur, mais qui a permis au coureur en troisième base de marquer ;
  • un amorti sacrifice ou une chandelle sacrifice;
  • une base sur balles, ou l'attribution de la première base pour avoir été touché par une balle lancée, ou pour interférence ou obstruction (avec les bases pleines), ce qui force le coureur en troisième base à franchir le marbre;
  • une erreur est commise sur une action où un coureur en troisième base marquerait normalement un point avant que deux coureurs ne soient éliminés..

ATTENTION: S'il y a deux retraits, un point marqué sur une balle frappée qui a entraîné une erreur, ou suite à une obstruction avec les bases pleines, ne peut jamais être comptabilisé comme un point produit, car si l'erreur n'avait pas été commise, la manche aurait été terminée et le point n'aurait pas été marqué.

Un point produit est inscrit dans la case du marbre, avec le numéro de frappeur ayant permis au coureur de marquer. Ce frappeur se voit créditer d'un point produit, dans la case appropriée.

Exemple 123: Avec des coureurs en première et troisième base, le frappeur frappe un double au champ droit, permettant aux deux coureurs de marquer.
Cela signifie que le quatrième frappeur dans l'ordre de passage au bâton se voit attribuer deux points produits.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un triple au champ centre. */
action { batter -> 3B8 }

/* Le coureur suivant atteint la première base suite à une obstruction du receveur. */
action { batter -> INT }

/* Le frappeur suivant frappe un double au champ droit, les deux coureurs marquent un point. */
action { batter -> 2B9 , runner1 -> +++ , runner3 -> + }

Exemple 124: Avec des coureurs en première et troisième base, le frappeur frappe un simple vers le champ centre, qui laisse passer la balle entre ses jambes. Les deux coureurs marquent alors un point et le frappeur atteint la deuxième base.
Le point marqué par le coureur depuis la troisième base est comptabilisé, car il a été marqué sur le coup sûr.
Le point marqué par le coureur depuis la première base n'est cependant pas un point produit car il est dû à une erreur du joueur de champ centre.
Dans cet exemple, on considère que le coureur parti de la première base aurait atteint la troisième base grâce à ce seul coup sûr.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un triple au champ centre. */
action { batter -> 3B8 }

/* Le coureur suivant remporte la première base sur un 'base on ball' */
action { batter -> BB }

/* Le frappeur suivant frappe un simple au champ centre et profite d'une erreur pour atteindre la deuxième base. Les deux coureurs avancent, et le deuxième coureur profite de l'erreur pour marquer. */
action { batter -> 1B8 e8 , runner1 -> ++ (3) , runner3 -> + }

Les parenthèses autour du chiffre quatre, qui enregistre le point marqué par le deuxième coureur, indiquent qu'il ne s'agit pas d'un point produit, car il a été obtenu en raison d'une erreur commise pendant le passage au bâton du quatrième frappeur, et non grâce à son coup sûr.

Exemple 125: Avec des coureurs en première et troisième base, le frappeur frappe vers l'arrêt-court, qui élimine le coureur de première base avec l'aide du défenseur de la deuxième base.
Le coureur parti de la troisième base marque.
Ce point compte comme un point produit, puisqu'il a été marqué sur la balle frappée.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un triple au champ centre. */
action { batter -> 3B8 }

/* Le coureur suivant remporte la première base sur un 'base on ball' */
action { batter -> BB }

/* Le frappeur envoie la balle en direction de l'arrêt-court, qui l'attrape et la transmet pour éliminer le coureur arrivant da la première base. */
action { batter -> O6 , runner1 -> 64 , runner3 -> + }

Exemple 126: Lorsque les bases sont pleines, le frappeur est touché par la balle et se rend directement en première base, obligeant les autres coureurs à avancer.
Le coureur en troisième base marque donc un point.
Ce point est comptabilisé comme un point produit, puisqu'il a été forcé par le frappeur.
La même situation se produit non seulement lorsqu'un frappeur-coureur atteint la première base sur un lancer frappé, mais aussi sur un but sur balles ou suite à une interférence.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un coup sûr au champ gauche. */
action { batter -> 1B7 }

/* Le frappeur suivant frappe un coup sûr au champ droit, le coureur avance de deux bases */
action { batter -> 1B9 , runner1 -> ++ }

/* Le frappeur suivant atteint la première base sur un 'base on ball' */
action { batter -> BB , runner1 -> + }

/* Le frappeur suivant atteint la première base sur un « Hit by pitch », tous les coureurs avancent. */
action { batter -> HP , runner1 -> + , runner2 -> + , runner3 -> + }

Exemple 127: Avec les première et deuxième bases occupées, le frappeur réussit un coup de circuit et trois points sont marqués.
Les trois points sont produits et sont attribués au frappeur (y compris son propre coup de circuit).

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un coup sûr au champ centre */
action { batter -> 1B8 }

/* Le frappeur suivant frappe un coup sûr au champ droit, le coureur avance d'une base */
action { batter -> 1B9 , runner1 -> + }

/* Le frappeur envoie la balle au champ centre, tout le monde marque. */
action { batter -> HR8 , runner1 -> +++ , runner2 -> ++ }

Exemple 128: La troisième base étant occupé, le frappeur envoie une balle en hauteur vers le champ centre et est éliminé.
Le coureur en troisième base quitte base après la prise et marque un point.
Le point est marqué et crédité au frappeur qui a réussi le sacrifice.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un triple au champ droit. */
action { batter -> 3B9 }

/* Le frappeur frappe un sacrifice fly au champ centre, le coureur marque */
action { batter -> SF8 , runner3 -> + }

AUCUN POINT PRODUIT n'est marqué suite à:

  • Une erreur défensive;
  • Un lancer sauvage, une balle passée ou un balk;
  • Un jeu où lorsque le batteur frappe un roulant dans un double-jeu forcé ou un double-jeu forcé inversé [OBR 9.04(b)(1)];
  • Une base volée;
  • Un choix défensif (O/).

Voici quelques exemples.

Exemple 129: Avec un coureur en troisième base, le lanceur effectue un lancer fou, permettant au coureur de marquer.
Ce point n'est pas un point produit. Il en va de même pour une balle passée.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un triple au champ centre. */
action { batter -> 3B8 }

/* Le coureur profite d'un lancer fou pour marquer le point. */
action { runner1 -> WP }

Exemple 130: Avec un coureur en deuxième base, le frappeur réussit un amorti sacrifice qui permet au coureur d'atteindre la troisième base.
Cependant, le lanceur, qui attrape le ballon amorti, rate son lancer vers la première base, permettant ainsi au coureur de marquer et au frappeur d'atteindre la deuxième base.
Le point n'est pas validé car il a été marqué suite à une erreur.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur frappe un double au champ gauche */
action { batter -> 2B7 }

/* Le frappeur suivant réussit un sacrifice, mais se retrouve sur les bases suite à une erreur. Le coureur avance et profite de l'erreur pour marquer. */
action { batter -> SHE1T+ , runner2 -> + (2) }

Exemple 131: Avec des coureurs en première et troisième base, le frappeur frappe vers l'arrêt-court qui passe la balle au défenseur de la deuxième base. Ce dernier élimine le coureur arrivant de la première base, puis lance vers le défenseur de la première base, réalisant un double jeu. Le coureur en troisième base marque.
L’avance du coureur de tête est parfaitement légale, même si le point ne peut être comptabilisé comme ayant été produit, car il a été inscrit suite à une balle frappée qui a conduit à un double jeu.
Dans ce cas, il est important de noter le numéro du frappeur dans l'ordre de passage au bâton, marqué d'un trait, afin de montrer qu'il ne s'agit pas d'un point produit, même si l'avance était légale.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un triple au champ centre. */
action { batter -> 3B8 }

/* Le frappeur suivant atteint la première base sur un 'base on ball' */
action { batter -> BB }

/* Le frappeur suivant frappe une balle au sol près de l'arrêt-court, ce qui provoque un double jeu ; le coureur en troisième base marque le point. */
action { batter -> GDP43 , runner1 -> 64 , runner3 -> + }

Exemple 132: Avec deux retraits et un coureur en troisième base, le frappeur frappe vers l'arrêt-court qui rate la prise, permettant au coureur en troisième base de marquer et au frappeur d'atteindre la première base en toute sécurité.
Le point n'est pas un point produit car il y avait déjà deux retraits, et si l'arrêt-court n'avait pas commis cette erreur, la manche aurait été terminée.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier frappeur réussit un triple au champ centre. */
action { batter -> 3BRC }

/* Le frappeur suivant atteint la première base suite à une erreur, et le coureur profite de cette erreur pour marquer le point. */
action { batter -> E6 , runner3 -> (2) }

Pour conclure cette section sur les points produits, nous allons profiter de cette occasion pour attirer votre attention sur une situation fréquente qui peut mettre le scoreur dans une situation délicate.

Prenons l'exemple suivant.

Exemple 133: Avec un coureur en deuxième base, le frappeur frappe un simple vers le champ centre, qui laisse passer la balle entre ses jambes.
Le coureur en deuxième base réussit à marquer, tandis que le frappeur atteint la deuxième base.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier coureur frappe un double au champ gauche */
action { batter -> 2B7 }

/* Le frappeur suivant frappe un coup sûr au champ centre et profite de l'erreur pour atteindre la deuxième base; le coureur marque. */
action { batter -> 1B8 e8 , runner2 -> ++ }

À ce stade, nous nous demandons si le point a été produit ou non, et si le coureur en deuxième base aurait marqué de toute façon, sans l'erreur du joueur de champ centre.

Pour résoudre correctement ce problème, le scoreur doit suivre de très près l'évolution de la situation sur le terrain et prendre particulièrement note de la position du coureur au moment où le défenseur a manqué la balle, et s'il était près du marbre ou loin, ce qui rendrait un lancer vers le marbre très difficile.

Il devrait noter attentivement si, une fois arrivé en troisième base, le coureur a ralenti puis a repris de la vitesse après avoir constaté l'erreur du joueur de champ, ou s'il a dépassé la troisième base en courant et a continué vers le marbre sans prêter attention à ce qui se passait dans le champ extérieur.

Si le marqueur détermine que le coureur se dirigeait de toute façon vers le marbre, et que le défenseur a commis l'erreur dans une position qui aurait rendu difficile pour lui d'effectuer un retrait au marbre, le frappeur devrait se voir créditer un point produit.

Sinon Exemple 134: Le point ne serait pas comptabilisé comme un point produit.

WBSC Transcription dans l'outil de scorage Outil
/* Le premier coureur frappe un double au champ gauche */
action { batter -> 2B7 }

/* Le frappeur suivant frappe un coup sûr au champ centre et profite de l'erreur pour atteindre la deuxième base, le coureur marque. */
action { batter -> 1B8 e8 , runner2 -> + (2) }
