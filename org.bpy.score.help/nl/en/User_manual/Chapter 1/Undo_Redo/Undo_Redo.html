Undo Redo.

While typing, it is possible to make a mistake, accidentally delete text, or simply change your mind. The editor keeps track of the changes you make, allowing you to undo them and, if necessary, redo them without having to retype everything.

The Undo command reverses the last change made in the editor whether it was text that was typed, deleted, pasted, or reformatted. It can be used multiple times in succession to move progressively further back through the history of changes.

  • Shortcut : Ctrl+Z.

  • Menu : Edit, puis Undo.

The Redo command is the opposite of the previous one: it reapplies a change that has just been undone. It is useful when you have undone too many changes.

  • Shortcut : Ctrl+Y.

  • Menu : Edit, puis Redo.
