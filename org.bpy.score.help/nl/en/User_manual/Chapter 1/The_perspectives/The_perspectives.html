The perspectives.

A perspective is a predefined layout of the Eclipse window: it determines which editors and views are displayed, where they are positioned, and which toolbars and menus are available. Each perspective is designed for a specific type of task.

Switching from one perspective to another therefore changes the window layout, without closing any open documents. This allows users to have a workspace tailored to each specific activity, rather than relying on a single, all-purpose window.

The tool currently offers a single perspective, dedicated to the manual entry of a match using the scoring language. It brings together everything required for this task:

  • The editors: the match editor, for recording actions, and the team editor, for describing the teams.

  • Specific views : the overall score, the active lineup, and the players' positions in the infield update as data is entered.

  • The input assistance features described above: syntax highlighting, auto-completion, templates, and real-time validation.

In this approach, the user writes out the sequence of the match, and the views immediately present the resulting situation.

Commands related to perspectives can be found in the Window menu, under the Perspective submenu.

After rearranging the window (moving, resizing, opening, or closing views), the Save Perspective As… command allows you to save this layout under a name of your choosing. It then appears in the list of available perspectives and can be used as a starting point for a custom layout.

The Reset Perspective command restores the original layout of the current perspective. It is useful if a view has been closed by mistake or if the window has become difficult to read. Only the layout is affected; documents remain unchanged.

The Open Perspective command displays a list of available perspectives. Selecting one immediately changes the layout of the window. Any documents that are already open remain open. If the perspective was already open, you are simply taken back to it.
