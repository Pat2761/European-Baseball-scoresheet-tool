Tool description

This tool allows you to record and track the scoring of a baseball game, play by play, from the first pitch to the final inning.

Today, there are many scoring software programs designed for the American format, the one used by Major League Baseball and most North American competitions. However, to my knowledge, there is currently no tool dedicated to the European scoring format, which features its own unique notation conventions and its own specific scoresheet.

This tool fills that gap: it adopts the logic and layout of the European scoresheet, while offering the convenience of digital entry (automatic calculations, data consistency, and easier error correction).

The tool complies with all the rules established by the Confederation of European Baseball (CEB). The notations, symbols, and scoring procedures are in accordance with current regulations, ensuring that the generated score sheets can be used in official competitions.
