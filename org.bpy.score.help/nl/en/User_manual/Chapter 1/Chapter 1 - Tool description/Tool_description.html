Tool description

This chapter describes the environment in which baseball games can be recorded. This tool is based on the Eclipse environment and leverages the capabilities it offers.

Eclipse is a framework that provides resources for creating applications containing views and editors. It also offers mechanisms for building menus and context menus, as well as a preferences (or options) editor, among other features that will not be detailed in this document.

This application provides various views and two editors specifically designed for baseball. The first editor is used to define a club, including the names of players and officials; the second allows for the recording of game actions and the individuals involved. The application also offers several other views: one for defining a league, creating its constituent clubs and games, and maintaining a list of them; an "Infield" view, which displays player positioning at any given moment during a game; a scoreboard; graphical representations of scorecards; the current game lineup; and more. The tool also incorporates standard views, such as the "Problems" view, which lists any errors or warnings detected in your data entry.
