Environment

The tool was developed entirely using the Eclipse platform. It is an application built on Eclipse RCP (Rich Client Platform), which allows for the creation of standalone desktop applications by reusing the infrastructure that underpins the success of the Eclipse development environment itself. The interface shown below is therefore based on the same principles as those of Eclipse: a main window, views, editors, toolbars, and menus.

This choice has brought numerous advantages for development:

  • A modular architecture: the application is broken down into plug-ins, which clearly separates responsibilities (data model, interface, scoring rules, etc.) and facilitates the maintenance and evolution of the tool.
  • A native and consistent interface: thanks to the SWT and JFace graphical libraries, the application integrates naturally into the operating system, offering a familiar experience for the user.
  • A comprehensive application framework: management of windows, preferences, help, keyboard shortcuts, and undo/redo mechanisms all without having to develop everything from scratch.
  • An integrated development environment: application editing, debugging, testing, and packaging are all performed within the same tool, which accelerates development cycles.
  • Simplified distribution: Eclipse makes it possible to produce an application that is ready for installation, complete with its own runtime environment.
