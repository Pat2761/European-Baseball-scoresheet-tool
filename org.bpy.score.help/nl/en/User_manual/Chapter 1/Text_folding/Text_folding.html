Text folding.

Collapsing allows you to temporarily hide a portion of the text, so that only the relevant parts remain on screen. This is useful in long documents for instance, to keep only the section you are currently working on visible.

In the left-hand margin of the editor, a small minus symbol (−) appears next to the beginning of each block that can be collapsed.

  • Clicking the minus sign (−) collapses the block: its content is hidden, with only the first line remaining visible, followed by an ellipsis. The symbol then changes to a plus sign (+).

  • Clicking the plus (+) sign expands the block and reveals all its content.

Hidden text is neither deleted nor modified: it remains in the document and continues to be taken into account for scoring.

Right-clicking in the margin opens a "Folding" menu, which offers options such as collapsing all, expanding all, or restoring the original state. These commands can also be accessed via keyboard shortcuts for example, using Ctrl + Numpad - to collapse a block, or Ctrl + Numpad + to expand the block located under the cursor.
