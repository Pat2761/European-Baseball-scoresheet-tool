The views

A view is a graphical component of the Eclipse interface that presents information or provides a tool to the user. Each view occupies a rectangular area within the main window, features its own tab, and serves a specific purpose—such as displaying a list, a tree structure, properties, results, and so on.

In addition to standard Eclipse views, the tool offers specific views designed to provide constant information about the match currently being recorded. These complement the match sheet and allow for an overall view without the need to scroll through the sheet itself.
