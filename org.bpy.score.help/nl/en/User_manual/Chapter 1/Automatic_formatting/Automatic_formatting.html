Automatic_formatting

Indentation consists of shifting text to the right based on its level of nesting. It makes the content easier to read: the structure of the document—that is, how elements relate to one another (such as a round, a team, an action, etc.) is immediately apparent. Well-indented text is easier to review, verify, and correct, and any errors or omissions are much more quickly spotted.

During the input process, it is normal for the text to become disorganized for example, following a copy-paste operation or multiple corrections. Indentation has no impact on scoring; it serves solely to improve the presentation.

There is no need to correct misalignments by hand: the editor can automatically reformat the text.

  • To format the entire document, click within the editor without selecting anything.

  • To format only a portion, first select the relevant rows.

  • Use the Ctrl+Shift+F shortcut, or right-click in the editor and select the formatting command (Format).
